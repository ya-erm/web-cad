# WebCAD

Параметрическая 2D/3D CAD-система в браузере по образцу Onshape. Работает **офлайн** и **без регистрации**: документы хранятся в IndexedDB этого браузера.

![Учебная пластина 40 × 30 × 10 мм со скруглениями радиусом 3 мм](docs/help/images/first-part-fillet.png)

Пошаговый пример — [Начало работы](docs/help/ru/getting-started.md). Иллюстрированная справка доступна в приложении через **?** или `F1`, на русском и английском языках.

## Запуск

```bash
npm install
npm run dev          # режим разработки: http://localhost:5173
```

Офлайн-сборка (PWA):

```bash
npm run build        # результат в dist/
npm run serve        # локальный сервер dist/: http://localhost:4173
```

После первого открытия Service Worker кэширует приложение вместе с геометрическим ядром (WASM, ~23 МБ). Дальше всё работает без сети, приложение можно установить из адресной строки браузера. Папку `dist/` можно отдать любым статическим сервером из любого каталога: пути относительные.

В dev-режиме автообновление (HMR) отключено, чтобы правки кода не сбрасывали незавершённый эскиз. После изменения кода страницу нужно перезагрузить вручную.

## Публикация на GitHub Pages

Сервер не нужен: сборка статическая, а ядро работает в однопоточном WASM без `SharedArrayBuffer`, поэтому особые заголовки (COOP/COEP) не требуются.

1. Загрузите проект в репозиторий на GitHub (ветка `main`).
2. В репозитории откройте **Settings → Pages → Build and deployment** и выберите **Source: GitHub Actions**.
3. Каждый push в `main` (или ручной запуск во вкладке **Actions**) выполняет [`.github/workflows/pages.yml`](.github/workflows/pages.yml): `npm ci`, тесты, сборку и публикацию `dist/`. Приложение откроется по адресу `https://<user>.github.io/<repo>/` и после первого визита будет работать офлайн.

Документы хранятся в браузере каждого посетителя, на сайт они не попадают. Мост для `npm run agent` — часть dev-сервера, поэтому на Pages он не работает: при загрузке приложение один раз запрашивает `__webcad/status`, получает ошибку и отключает мост. `window.webcad` в консоли страницы при этом доступен.

## Возможности

- **Документы**: список, создание, переименование, дублирование, удаление, импорт и экспорт проекта (`.webcad.json`).
- **Part Studio**:
  - дерево фич с откатом (rollback bar), подавлением, переименованием, папками и перетаскиванием;
  - список деталей с цветами и скрытием;
  - переменные (`#width`); в любом числовом поле можно писать выражения с единицами (`25 mm`, `#w/2 + 1 in`).
- **Эскиз**:
  - примитивы: линия, прямоугольники, окружности, дуги (по 3 точкам, касательная, по центру), сплайн, точка, паз, многоугольник, эллипс;
  - правка: скругление углов, обрезка, вспомогательная геометрия;
  - автопривязки к точкам, кривым, серединам, началу координат, горизонтали и вертикали;
  - ограничения: совпадение, концентричность, параллельность, касание, H/V, перпендикулярность, равенство, середина, симметрия, фиксация;
  - размеры, в том числе с выражениями, и перетаскивание с решателем;
  - цвет статуса: синий — недоопределён, чёрный — определён, красный — переопределён.
- **3D-фичи** (ядро OpenCascade):
  - выдавливание (New/Add/Remove/Intersect, на глубину, симметрично, до грани, насквозь, второе направление, уклон, тонкостенное);
  - вращение, sweep, loft, утолщение;
  - скругление, фаска, оболочка, уклон, отверстия (простые, с цековкой, с зенковкой);
  - линейный и круговой массив, зеркало (детали или фичи);
  - булевы операции, разделение, перемещение, удаление детали;
  - плоскости, спираль, импорт STEP/STL.
- **Измерения**: длина, площадь, объём, масса, центр масс, расстояние между элементами.
- **Чертежи**:
  - листы A4–A0 с рамкой и основной надписью;
  - стандартные виды (первый угол ISO/ГОСТ или третий угол ANSI) с удалением невидимых линий;
  - размеры, примечания;
  - экспорт в PDF, SVG, DXF.
- **Экспорт**: STEP, STL (бинарный и ASCII), OBJ, 3MF; DXF эскиза.

## Управление

| Действие | Мышь / клавиши |
|---|---|
| Вращение | ПКМ + перетаскивание |
| Панорама | СКМ или Ctrl + ПКМ + перетаскивание |
| Масштаб | Колесо (к курсору) |
| Стандартные виды | Shift+1…7 (Front, Back, Left, Right, Top, Bottom, Iso) |
| Показать всё / вид по нормали | F / N |
| Эскиз, выдавливание, вращение, скругление | Shift+S, Shift+E, Shift+W, Shift+F |
| Инструменты эскиза | L линия, G прямоугольник, R от центра, C окружность, A дуга, M обрезка, O смещение, U проекция (Use), D размер, Q вспомогательная |
| Ограничения | I совпадение, H/V, B параллельность, T касание, E равенство, Shift+L перпендикулярность, Shift+Q симметрия, Shift+J фиксация |
| Принять / отмена | Enter / Esc |

## API для агентов

Модели можно создавать и править декларативными операциями (JSON) — из терминала, пока приложение открыто в браузере, или без браузера:

```bash
npm run agent -- create "Пластина"
npm run agent -- run '[{"op":"sketch","shapes":[{"type":"rect","center":true,"w":40,"h":30}]},{"op":"extrude","depth":10},{"op":"fillet","edges":{"dir":"z"},"radius":3}]'
npm run agent -- shot plate.png iso
npm run agent -- build ops.json --out model.webcad.json --stl model.stl   # headless
```

В странице то же доступно как `window.webcad`. Справочник: [docs/agent-api.md](docs/agent-api.md).

## Архитектура

- `src/kernel`: Web Worker с OpenCascade (replicad). Инкрементальная пересборка истории фич с кэшем, tessellation, persistent naming по геометрическим сигнатурам, экспорт, HLR-проекции.
- `src/sketch`: решатель ограничений (Gauss–Newton с минимальной нормой и анализом степеней свободы), поиск замкнутых регионов, операции над эскизом.
- `src/viewport`: Three.js-вид, GPU-пикинг, камера в стиле Onshape, куб видов, редактор эскиза.
- `src/ui`, `src/drawing`: интерфейс на React, чертежи.
- `src/export`: собственные писатели DXF, SVG, PDF, 3MF, STL, OBJ и ZIP.
- `src/agent`, `scripts/webcad.mjs`: API для агентов (операции, запросы граней и рёбер, мост через dev-сервер, headless-режим).

Тесты: `npm test` (включая интеграционные тесты ядра на WASM в Node).
