# Mirror

Creates a mirrored copy of parts or features about a plane.

**Toolbar:** **Mirror**

## Steps {#steps}

1. Click **Mirror**.
2. Choose **Part pattern** or **Feature pattern** and specify what to mirror.
3. Click the **Mirror plane** field and select a plane or a planar face.
4. Click ✓ (`Enter`).

## Options {#options}

| Field | Description |
|---|---|
| **Part pattern** / **Feature pattern** | Mirror whole parts or the result of the selected features. |
| **Parts to mirror** / **Features to mirror** | What to mirror. |
| **Mirror plane** | A plane (**Top**, **Front**, **Right**, [Plane](plane)) or a planar face. |
| **New** / **Add** | For parts: the mirrored copy is a separate part or merges with the original. |

> **Tip.** To build a symmetric part, model one half and mirror it with the **Add** operation about the plane of symmetry.
