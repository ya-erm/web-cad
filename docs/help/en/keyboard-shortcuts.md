# Keyboard shortcuts

Shortcuts are bound to physical keys, so they also work with the Russian keyboard layout. On macOS, you can press `Cmd` instead of `Ctrl`. While the cursor is in a text field, shortcuts do not work.

## General {#general}

| Keys | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y`, `Ctrl+Shift+Z` | Redo |
| `F1` | Help for the current tool or dialog |
| `Esc` | Close the feature dialog without saving / clear the selection |
| `Enter` | Accept the feature dialog |
| `Shift+Enter` | Accept the dialog and immediately start the same feature |
| `Space` | Clear the selection |
| `Del`, `Backspace` | Delete the features selected in the feature list |
| `Shift+N` | Rename the feature selected in the feature list |
| `Alt+C` (`Option+C`) | Go to the **Search tools** field |
| `Shift+/` (`?`) | Open this list of shortcuts |

## Part Studio features {#features}

| Keys | Action |
|---|---|
| `Shift+S` | [Sketch](sketch) |
| `Shift+E` | [Extrude](extrude) |
| `Shift+W` | [Revolve](revolve) |
| `Shift+F` | [Fillet](fillet) |

Start other features with the toolbar buttons or the **Search tools** field.

## View {#view}

| Keys | Action |
|---|---|
| `F` | Zoom to fit |
| `N` | View normal to |
| `Shift+1` … `Shift+6` | Front, Back, Left, Right, Top, Bottom views |
| `Shift+7` | Isometric |
| `←` `→` `↑` `↓` | Rotate the view 15° |
| `Ctrl` + arrow | Rotate the view 5° |
| `Shift` + arrow | Rotate the view 90° |
| `Shift+Z` / `Z` | Zoom in / zoom out |
| `P` | Show or hide planes |
| `Shift+H` | Show or hide sketches |
| `Shift+X` | Turn the [section view](section-view) on or off |
