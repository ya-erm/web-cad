# Обрезка

Удаляет участок кривой между соседними точками пересечения с другими кривыми.

**Панель эскиза:** **Обрезка** · **Клавиша:** `M`

```figure

```

## Порядок действий {#steps}

1. Нажмите **Обрезка** (`M`).
2. Щёлкните участок кривой, который нужно удалить. Удаляется кусок между ближайшими пересечениями по обе стороны от точки щелчка (или до конца кривой, если пересечений нет).
3. Продолжайте щёлкать другие участки; `Esc` — выйти из инструмента.

## Особенности {#details}

- Работает с линиями, дугами и окружностями (обрезанная окружность становится дугой).
- Оставшаяся часть кривой сохраняет её идентичность, поэтому ограничения и размеры, наложенные на неё, по возможности сохраняются.
- Если на кривой нет ни одного пересечения, щелчок удаляет её целиком.
