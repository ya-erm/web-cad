# Разделение

Разрезает детали и [поверхности](offset-surface#surfaces) на части плоскостью, гранью или поверхностью, как Split в Onshape.

**Панель инструментов:** **Разделение**

## Порядок действий {#steps}

1. Нажмите **Разделение**.
2. В поле **Детали и поверхности для разделения** выберите, что резать.
3. Щёлкните поле **Чем разделить** и выберите плоскость, соединитель, грань детали или поверхность. Поверхность целиком выбирается в списке деталей (группа «Поверхности»), щелчок по ней в окне выбирает одну её грань.
4. Нажмите ✓ (`Enter`).

Каждая деталь или поверхность, которую пересекает инструмент, распадается на несколько: одна часть сохраняет исходное имя, остальные становятся новыми деталями (поверхностями). При разделении плоскостью исходное имя остаётся у части со стороны нормали плоскости. Если инструмент ничего не пересекает, появится сообщение «Инструмент разделения не пересекает выбранные детали».

## Инструменты {#tools}

| Инструмент | Как режет |
|---|---|
| Плоскость, соединитель | По всей плоскости. |
| Плоская грань | По всей своей плоскости; с флажком **Обрезать по границам грани** — только в пределах грани. |
| Неплоская грань (цилиндр, сфера и т. п.) | В пределах самой грани. |
| Поверхность | В пределах поверхности. После разделения она удаляется, если не включён флажок **Сохранить инструменты**. Деталь как инструмент не подходит — выберите её грань. |

Деталь делится, только если инструмент проходит её насквозь: поверхность, которая кончается внутри детали, её не разрежет.

## Обрезка поверхностей друг о друга {#trim}

Две пересекающиеся поверхности обрезаются по линии пересечения так:

1. Разделите первую поверхность второй с флажком **Сохранить инструменты**.
2. Разделите вторую поверхность одним из кусков первой (его край лежит на линии пересечения — по ней и пройдёт разрез).
3. Удалите лишние куски фичей [Удалить деталь](delete-part).
4. Объедините оставшиеся [булевой операцией](boolean#surfaces) **Объединение**: они сошьются по общему ребру в одну поверхность. Её можно [утолщить](thicken) или, если она замыкает объём, [сшить в тело](enclose).

Поверхность можно обрезать и деталью: [вычтите](boolean#surfaces) деталь из поверхности.
