# Разделение

Разрезает детали плоскостью на отдельные детали.

**Панель инструментов:** **Разделение**

## Порядок действий {#steps}

1. Нажмите **Разделение**.
2. В поле **Детали для разделения** выберите детали.
3. Щёлкните поле **Режущая плоскость** и выберите плоскость или плоскую грань.
4. Нажмите ✓ (`Enter`).

Каждая деталь, которую пересекает плоскость, превращается в несколько деталей: часть по одну сторону сохраняет исходную деталь, части по другую становятся новыми деталями. Если плоскость не пересекает ни одну деталь, появится сообщение «Инструмент разделения не пересекает выбранные детали».

> **Ограничение.** Резать можно только плоскостью; разделение поверхностью или другой деталью пока не поддерживается.
