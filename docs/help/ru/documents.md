# Документы и вкладки

## Страница документов {#documents-page}

caption: Кнопки слева создают новый документ или открывают файл проекта. Щелчок по карточке открывает существующий документ.

Страница **Документы** открывается при запуске WebCAD и по щелчку на логотип ◆ в редакторе. На ней показаны все документы этого браузера с миниатюрой, именем и датой изменения.

| Действие | Как выполнить |
|---|---|
| Создать документ | Кнопка **Создать** (или **Новый документ**, если документов ещё нет). Новый документ сразу открывается. |
| Открыть | Щелчок по карточке документа. |
| Переименовать | Наведите курсор на карточку и нажмите **Переименовать**; `Enter` — сохранить, `Esc` — отменить. В открытом документе имя меняется прямо в верхней панели. |
| Дублировать | Кнопка **Дублировать** на карточке. |
| В корзину | Значок корзины на карточке (**В корзину**). Документ исчезнет из списка; его можно восстановить. |
| Импорт проекта | Кнопка **Импорт проекта** — открыть файл `.webcad.json` как новый документ. |
| Папка на компьютере | Документы — файлы папки, сохраняются сами (Chrome, Edge), см. [ниже](#folder). |

Миниатюра обновляется, пока документ открыт, и при возврате к списку документов.

У каждого документа свой адрес вида `#/doc/<id>` — его можно добавить в закладки этого браузера.

## Корзина и восстановление {#trash}

1. Нажмите **Корзина** слева на странице документов.
2. Найдите документ и нажмите **Восстановить** — он вернётся в **Документы**.

**Удалить навсегда** удаляет один документ из корзины, **Очистить корзину** — все документы в ней. Для этих действий требуется повторное нажатие кнопки. После окончательного удаления восстановить документ можно только из заранее сохранённого файла проекта.

## Вкладки документа {#tabs}

Документ состоит из вкладок, они показаны в нижней панели:

- **Part Studio** — трёхмерное моделирование: эскизы, фичи, детали;
- **Чертёж** — листы с видами деталей, см. [Чертежи](drawings).
- **Сборка** — экземпляры деталей из Part Studio, расставленные в изделие, см. [Сборка](assembly).

Кнопка **+** слева от вкладок добавляет новую вкладку **Part Studio**, **Чертёж** или **Сборка**. Двойной щелчок по вкладке переименовывает её. Правый щелчок открывает меню **Переименовать** / **Удалить** (последнюю вкладку удалить нельзя).

## Сохранение и отмена {#saving}

- Все изменения сохраняются автоматически, состояние показано рядом с именем документа: **Сохранено** или **Сохранение…**.
- **Отменить** (`Ctrl+Z`) и **Повторить** (`Ctrl+Y` или `Ctrl+Shift+Z`) работают для всего документа. Пока открыт диалог фичи, отмена документа недоступна; в эскизе действует собственная история отмены эскиза.
- Если перезагрузить страницу посреди редактирования эскиза или фичи, незавершённая работа восстановится.

## Файлы проекта {#project-files}

Документ целиком (все вкладки, история фич, настройки) можно сохранить в файл и открыть в другом браузере или на другом компьютере:

1. В открытом документе откройте **Настройки** → **Экспорт проекта**. Скачается файл `<имя>.webcad.json`.
2. На странице **Документы** нажмите **Импорт проекта** и выберите этот файл.

> **Совет.** Файлы проекта — простой способ сделать резервную копию: документы хранятся только в этом браузере, см. [Офлайн-работа и хранение](offline). Чтобы файлы обновлялись сами, работайте в [папке на компьютере](#folder).

Экспорт геометрии в STEP, STL и другие форматы описан на странице [Импорт и экспорт](import-export).

## Папка на компьютере {#folder}

В Chrome и Edge WebCAD может работать прямо с папкой на компьютере: документы в ней — это файлы проекта `*.webcad.json`, которые сохраняются автоматически. Такую папку удобно копировать, архивировать, держать в Git или в облачной папке (Яндекс Диск, Dropbox и т. п.).

1. На странице документов нажмите **Папка на компьютере** слева, затем **Выбрать папку…**, и разрешите браузеру просматривать и изменять файлы в ней.
2. Карточки показывают файлы WebCAD этой папки. Щелчок по карточке открывает документ.
3. **Новый документ в папке** создаёт документ сразу файлом папки. Документ из браузера можно перенести в папку значком папки на его карточке (**Сохранить в папку**).

Как это работает:

- открытый из папки документ связан со своим файлом: каждое автосохранение записывает и файл (имя файла показано рядом с **Сохранено**), а карточка в **Документах** отмечена значком папки;
- главная копия — файл. При открытии из папки берётся файл, а если в браузере есть более новые изменения, которые не удалось записать, — они записываются в файл;
- файл с тем же документом, но под другим именем (копия) открывается отдельным документом;
- папка запоминается. После перезапуска браузер снова спрашивает разрешение: нажмите **Разрешить доступ** на странице папки или **Разрешить запись в папку** в открытом документе — накопившиеся изменения запишутся в файл;
- **Другая папка…** выбирает новую папку, **Забыть папку** отключает её. Файлы и документы при этом остаются, но больше не связаны.

> **Ограничение.** Переименование, удаление и корзина документа в браузере не меняют его файл. Изменения файла другими программами WebCAD видит при следующем открытии документа из папки (кнопка **Обновить** перечитывает список файлов). В Firefox и Safari папки недоступны — пользуйтесь **Экспортом** и **Импортом проекта**.
