# Уклон

Наклоняет грани детали на заданный угол относительно направления извлечения из формы — так делают литейные уклоны.

**Панель инструментов:** **Уклон**

## Порядок действий {#steps}

1. Нажмите **Уклон**.
2. В поле **Нейтральная плоскость** выберите плоскость или плоскую грань. Её нормаль — направление извлечения; по линии пересечения с нейтральной плоскостью грани не смещаются.
3. Щёлкните поле **Грани для уклона** и выберите боковые грани.
4. Задайте **Угол уклона** (кнопка рядом меняет направление наклона), нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Нейтральная плоскость** | Плоскость или плоская грань. |
| **Грани для уклона** | Наклоняемые грани. |
| **Угол уклона** | Угол наклона (по умолчанию 3°). |

> **Совет.** Уклон боковых стенок можно задать сразу при выдавливании — флажок **Уклон** в [Выдавливании](extrude).
