# Размер смещения

Размер, который создаёт инструмент [Смещение](sketch-offset): одно расстояние между исходной цепочкой кривых и её эквидистантой.

|---|---|
| ![Предпросмотр смещения с текущим расстоянием у курсора](../images/sketch-offset-preview.png) | ![Смещённая цепочка и размер 8](../images/dimension-offset.png) |

## Как появляется {#create}

1. Инструментом **Смещение** (`O`) выберите цепочку и щёлкните сторону — см. [Смещение](sketch-offset).
2. Сразу откроется поле размера с измеренным расстоянием — введите точное значение и нажмите `Enter`.

Отдельно инструментом **Размер** размер смещения не создаётся.

## Как работает {#how}

- Один размер управляет всеми парами «исходная кривая — копия» в цепочке: каждая копия остаётся параллельной (для дуг — концентричной) своей исходной кривой на заданном расстоянии.
- Сторона смещения сохраняется: копия не перескочит на другую сторону.
- Если изменить исходную цепочку (размеры, перетаскивание), копия последует за ней.

## Изменение и удаление {#edit}

- Двойной щелчок по размеру — новое значение (можно выражение: `#wall`).
- Удаление размера (`Del`) оставляет копию, но разрывает связь расстояния.
- Если удалить часть копии, из размера убирается только эта пара.
