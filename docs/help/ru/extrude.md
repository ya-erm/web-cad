# Выдавливание

Создаёт тело, выдавливая области эскиза или плоские грани перпендикулярно их плоскости. Может создать новую деталь, добавить материал к существующим, вырезать его или оставить пересечение.

**Панель инструментов:** **Выдавливание** · **Клавиши:** `Shift+E`

## Порядок действий {#steps}

1. Выберите области эскиза или плоские грани (можно щёлкнуть эскиз в [списке фич](feature-list) — выберутся все его области).
2. Нажмите **Выдавливание** (`Shift+E`).
3. Выберите тип операции: **Новая**, **Добавить**, **Вычесть** или **Пересечь**.
4. Выберите **Окончание** и задайте **Глубина** (или грань для **До грани**).
5. При необходимости включите **Тонкостенное**, **Уклон** или **Второе направление**.
6. Нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Новая** / **Добавить** / **Вычесть** / **Пересечь** | Тип операции, см. [Диалоги фич](feature-dialogs#operation). |
| **Грани и области эскиза** | Профили: замкнутые области эскизов или плоские грани деталей. |
| **Окончание** | **На глубину** — на заданное расстояние; **Симметрично** — на половину глубины в обе стороны от плоскости эскиза; **До грани** — до выбранной плоскости, плоской грани, вершины или точки эскиза; **Насквозь** — через всю модель. |
| **До** | Для **До грани**: плоскость, плоская грань, вершина или точка эскиза, до которой идёт выдавливание. Плоскость не должна быть параллельна направлению. |
| **Глубина** | Расстояние выдавливания (по умолчанию 25 мм). Кнопка рядом разворачивает направление. |
| **Противоположное направление** | Для **До грани** и **Насквозь**: выдавить в другую сторону. |
| **Тонкостенное**, **Толщина** | Вместо сплошного тела строится стенка заданной толщины вдоль внешнего контура профиля. Кнопка рядом с толщиной переносит стенку наружу. |
| **Уклон**, **Угол уклона** | Боковые грани наклоняются на заданный угол (сужение или расширение). Кнопка меняет направление наклона. |
| **Второе направление** | Выдавить также в обратную сторону от плоскости эскиза; у второго направления своё **Окончание** (**На глубину**, **До грани**, **Насквозь**) и **Глубина**. Недоступно для **Симметрично**. |
| **Объединить со всеми** / **Область объединения** | Для **Добавить**, **Вычесть**, **Пересечь**: с какими деталями выполнять операцию. |

## Поверхность {#surface}

Переключатель **Твёрдое тело / Поверхность** вверху диалога. В режиме **Поверхность** выдавливаются не области, а **Кривые эскиза** — в том числе незамкнутые (отрезок, ломаная, дуга): получается [поверхность](offset-surface#surfaces) «Surface N» без толщины. Окончание — **На глубину**, **Симметрично** или **Насквозь** (и второе окончание); тонкие стенки, уклон и булевы операции для поверхности не применяются. Поверхности можно [утолщить](thicken) или [сшить в тело](enclose).

## Советы {#tips}

- **Вычесть** + **Насквозь** — быстрый способ сделать сквозной вырез. Для круглых отверстий удобнее [Отверстие](hole).
- Глубину можно связать с переменной: `#t`, `#height - 2 mm`.
- Сообщение «Нечего вырезать: инструмент не касается ни одной детали» означает, что вырезаемое тело не касается ни одной детали — проверьте направление.

> **Ограничение.** В режиме **Тонкостенное** используется только внешний контур профиля; внутренние контуры (отверстия в области) не учитываются.
