# Плоскость

Создаёт вспомогательную плоскость — для эскизов, зеркала, разделения, лофта и других фич.

**Панель инструментов:** **Плоскость**

## Порядок действий {#steps}

1. Нажмите **Плоскость**.
2. Выберите **Тип плоскости**.
3. В поле **Элементы** выберите опорную геометрию (см. таблицу).
4. Задайте смещение или угол, нажмите ✓ (`Enter`).

## Типы плоскостей {#types}

| Тип | Что выбрать | Параметры |
|---|---|---|
| **Смещение** | Плоскость или плоскую грань | **Смещение** — расстояние вдоль нормали (по умолчанию 10 мм); кнопка рядом — в другую сторону. |
| **Точка и нормаль** | Точку (вершину, точку эскиза, начало координат) и направление (линию эскиза, прямое ребро, плоскость или грань) | Плоскость проходит через точку перпендикулярно направлению. **Развернуть нормаль** меняет её сторону. |
| **По трём точкам** | Три точки | Плоскость через три точки (не на одной прямой). **Развернуть нормаль**. |
| **Линия и угол** | Линию (линию эскиза или прямое ребро) и, при желании, опорную плоскость | Плоскость проходит через линию под **Угол** к опорной плоскости (по умолчанию 30°). |
| **Средняя плоскость** | Две параллельные плоскости или плоские грани | Плоскость посередине между ними. |

## Использование {#use}

- Плоскость появляется в [списке фич](feature-list) и в графической области. Её можно скрыть значком глаза; все плоскости — клавишей `P`.
- Выберите плоскость и нажмите **Эскиз** (`Shift+S`), чтобы рисовать на ней.
- Размер плоскости подбирается автоматически по размеру модели.
