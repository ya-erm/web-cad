# Перемещение

Перемещает, поворачивает или масштабирует детали — либо их копии.

**Панель инструментов:** **Перемещение**

## Порядок действий {#steps}

1. Нажмите **Перемещение**.
2. Выберите **Тип перемещения**.
3. В поле **Детали** выберите детали.
4. Задайте параметры выбранного типа (см. ниже).
5. Чтобы исходная деталь осталась на месте, включите **Копировать деталь**.
6. Нажмите ✓ (`Enter`).

## Типы перемещения {#types}

| Тип | Параметры |
|---|---|
| **Сдвиг по XYZ** | **X**, **Y**, **Z** — сдвиг вдоль осей координат (по умолчанию 0, 0, 10 мм). |
| **Сдвиг вдоль элемента** | **Направление** — линия эскиза, ребро, плоская грань или плоскость (по нормали), цилиндрическая грань (по оси), [соединитель](mate-connector) (по оси Z); **Расстояние** и кнопка разворота. |
| **Поворот** | **Ось** — линия эскиза, прямое или круговое ребро, цилиндрическая грань, соединитель; **Угол** и кнопка разворота. |
| **Масштаб** | **Точка** — центр масштабирования (вершина, точка эскиза, начало координат, центр кругового ребра; если не выбрана — начало координат); **Масштаб** — коэффициент (больше 0). |
| **От соединителя к соединителю** | См. [ниже](#mates). |

**Копировать деталь** — перемещается не сама деталь, а её новая копия.

Соединители, которыми [владеет](mate-connector#owner) перемещаемая деталь, перемещаются вместе с ней (кроме режима **Копировать деталь**).

## От соединителя к соединителю {#mates}

Совмещает детали так, чтобы один [соединитель](mate-connector) встал на место другого: совпадают их начала и оси.

1. Создайте соединитель на перемещаемой детали (например, в центре нижней грани) и соединитель в месте назначения.
2. В **Перемещении** выберите тип **От соединителя к соединителю**.
3. Выберите **Детали**, затем **Перемещаемый соединитель** и **Соединитель назначения**.
4. Нажмите ✓.

> **Совет.** Чтобы развернуть деталь при совмещении, измените у соединителя **Развернуть основную ось** или **Поворот вокруг Z**.
