# Список фич

Список **Фичи** в левой панели — это история построения Part Studio. Фичи выполняются сверху вниз; каждая может использовать результат предыдущих. Число в заголовке — количество фич. Если у Part Studio есть [конфигурации](configurations), над списком стоят их входы: выберите вариант, и модель перестроится в нём.

## Исходная геометрия {#default-geometry}

Группа **Исходная геометрия** (сворачивается щелчком по заголовку) содержит **Начало координат** и три плоскости: **Top**, **Front**, **Right**. В графической области имя каждой плоскости написано на ней самой — в её углу вдоль края, как в Onshape (если смотреть на плоскость с обратной стороны, надпись всё равно читается слева направо).

- Щелчок по плоскости выбирает её, значок глаза скрывает или показывает её.
- Двойной щелчок по плоскости сразу начинает на ней [эскиз](sketch).
- Пока диалог эскиза ждёт плоскость (поле **Плоскость эскиза** активно), щелчок по **Top**, **Front**, **Right** или по [плоскости](plane) в списке ставит эскиз на неё. Плоскость из списка должна стоять выше эскиза.

## Фичи в списке {#items}

Каждая строка показывает значок типа и имя фичи. Для [переменных](variables) рядом видно `#имя = выражение`.

- **Красная точка** — фича не построилась (ошибка). Наведите курсор на строку, чтобы прочитать сообщение.
- **Жёлтая точка** — фича построилась с предупреждением.
- **Серая строка** — фича отключена или находится ниже полосы отката.
- У эскизов, плоскостей и спиралей есть значок глаза — скрыть или показать их в графической области.

## Выбор и редактирование {#selecting}

- Щелчок выбирает фичу, `Ctrl`/`Cmd` + щелчок добавляет к выбору, `Shift` + щелчок выбирает диапазон.
- Щелчок по эскизу выбирает все его замкнутые области — после этого можно сразу нажать [Выдавливание](extrude) или [Вращение](revolve).
- Если открыт диалог фичи и активно поле, принимающее области эскиза, щелчок по эскизу в списке добавляет в поле все его области.
- Двойной щелчок открывает фичу для редактирования. Во время редактирования фичи ниже неё временно показываются как откатанные.
- Щелчок по пустому месту списка или в графической области снимает выбор в списке.
- `Del` или `Backspace` удаляет выбранные фичи.

## Контекстное меню {#context-menu}

Правый щелчок по фиче:

| Пункт | Что делает |
|---|---|
| **Редактировать** | Открывает диалог фичи (или эскиз). |
| **Переименовать** | Меняет имя в списке. |
| **Отключить** / **Включить** | Отключённая фича не выполняется, как будто её нет, но остаётся в списке. |
| **Откатить сюда** | Ставит полосу отката сразу после этой фичи. |
| **Откатить в конец** | Возвращает полосу отката в конец списка. |
| **Скрыть** / **Показать** | Для эскизов, плоскостей и спиралей. |
| **Экспорт DXF** | Для эскизов: сохраняет эскиз в файл DXF. |
| **Добавить в новую папку** / **Убрать из папки** | См. [Папки](#folders). |
| **Удалить** | Удаляет фичу. Фичи, которые на неё ссылались, могут перестать строиться. |

Если выбрано несколько фич, меню применяется ко всем: **Добавить в новую папку**, **Отключить** / **Включить**, **Скрыть / Показать**, **Удалить (N)**.

## Полоса отката {#rollback}

Синяя полоса в списке отмечает, до какого места выполняется история. Фичи ниже полосы не строятся и показаны серым.

- Перетащите полосу мышью вверх или вниз, чтобы посмотреть модель на любом шаге.
- Новые фичи вставляются в месте полосы — так можно добавить фичу в середину истории.
- **Откатить сюда** и **Откатить в конец** в контекстном меню делают то же самое без перетаскивания.

## Порядок фич {#reorder}

Фичи можно перетаскивать мышью: строка вставляется перед той, на которую её бросили. Перетаскивать можно и несколько выбранных фич сразу.

> **Внимание.** Фича может ссылаться только на то, что построено выше неё. Если перенести фичу выше её эскиза или грани, на которой она построена, она перестанет строиться — тогда верните порядок или отмените перенос (`Ctrl+Z`).

## Папки {#folders}

Папки помогают группировать фичи. В папку объединяются только фичи, идущие подряд.

1. Выберите одну или несколько соседних фич.
2. Нажмите **Добавить в новую папку** в контекстном меню (или кнопку папки в заголовке списка).
3. Введите имя папки и нажмите `Enter`.

Щелчок по стрелке сворачивает или разворачивает папку, двойной щелчок по имени — переименовывает. Фичу можно бросить на папку, чтобы переместить её внутрь. Контекстное меню папки: **Переименовать**, **Свернуть** / **Развернуть**, **Выбрать содержимое**, **Отключить** / **Включить**, **Скрыть / Показать**, **Разгруппировать** (убрать папку, фичи остаются), **Удалить папку с фичами**.
