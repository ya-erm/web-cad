# Зеркало в эскизе

Создаёт зеркальные копии элементов эскиза относительно линии.

**Панель эскиза:** **Зеркало в эскизе**

## Порядок действий {#steps}

Инструмент работает двумя способами.

**Сначала инструмент, потом линия и элементы** (как в Onshape):

1. Ничего не выбирая, нажмите **Зеркало в эскизе** — кнопка останется нажатой, в строке состояния появится подсказка.
2. Щёлкните линию — ось отражения (обычно вспомогательную). Она останется выделенной.
3. Щёлкайте элементы: каждый отражается сразу, инструмент ждёт следующих. Повторный щелчок по уже отражённому элементу или по копии ничего не добавляет.
4. Нажмите `Esc` (или снова кнопку), чтобы закончить.

Если перед нажатием кнопки выбраны элементы без линии, они отразятся, как только вы щёлкнете линию; если выбрана только линия, она сразу становится осью.

**Сначала выбор, потом инструмент:**

1. В режиме выбора выберите элементы, которые нужно отразить.
2. **Последней** выберите линию — ось отражения.
3. Нажмите **Зеркало в эскизе** — копии появятся сразу.

## Особенности {#details}

- Копии связаны с оригиналами ограничениями **Симметрия** относительно оси (для окружностей — ещё **Равенство**). Если изменить или передвинуть оригинал, копия последует за ним.
- Ось может быть любой линией эскиза; удобно провести вспомогательную линию через начало координат.
