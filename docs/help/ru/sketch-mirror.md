# Зеркало в эскизе

Создаёт зеркальные копии элементов эскиза относительно линии.

**Панель эскиза:** **Зеркало в эскизе**

```figure
image: ../images/sketch-mirror-steps.svg
alt: Контур и его зеркальная копия относительно вертикальной оси
caption: Сначала выберите исходный контур (1), последней — линию-ось (2). Оранжевым показана создаваемая копия; ось не копируется.
width: 600
```

## Порядок действий {#steps}

1. В режиме выбора выберите элементы, которые нужно отразить.
2. **Последней** выберите линию — ось отражения (обычно вспомогательную).
3. Нажмите **Зеркало в эскизе**.

Если линия не выбрана или выбрана не последней, появится сообщение «Выберите элементы и линию отражения (линию — последней)».

## Особенности {#details}

- Копии связаны с оригиналами ограничениями **Симметрия** относительно оси (для окружностей — ещё **Равенство**). Если изменить или передвинуть оригинал, копия последует за ним.
- Ось может быть любой линией эскиза; удобно провести вспомогательную линию через начало координат.
