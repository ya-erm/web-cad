# Импорт

Добавляет в Part Studio тела из файлов STEP или STL. Каждое твёрдое тело файла становится отдельной деталью.

**Панель инструментов:** **Импорт**

## Порядок действий {#steps}

1. Нажмите **Импорт**.
2. Нажмите кнопку **STEP / STL…** в поле **Файл** и выберите файл `.step`, `.stp` или `.stl`.
3. Для STL оставьте или снимите флажок **Распознавать поверхности** (см. ниже).
4. Дождитесь предпросмотра и нажмите ✓ (`Enter`).

Имя фичи берётся из имени файла.

## Распознавание поверхностей STL {#recognize}

STL хранит только треугольники. С флажком **Распознавать поверхности** (включён по умолчанию) WebCAD находит, какие треугольники лежат на одной плоскости, цилиндре, конусе или сфере, и строит деталь из настоящих граней — как деталь из CAD: отверстие становится одной цилиндрической гранью с круглыми рёбрами, фаска — конусом, скругление — частью цилиндра, шар — сферой. Такую деталь удобно мерить (радиус, ось), к ней привязываются отверстия и соединители, а модель не покрыта штриховкой рёбер треугольников.

- Границы граней строятся точно: две плоскости встречаются по прямой, плоскость поперёк оси цилиндра, конуса или сферы — по окружности, соосные цилиндр и конус — тоже по окружности; остальные границы — сплайны через точки сетки.
- Распознанная деталь проверяется: она должна быть правильным телом того же объёма, что и сетка (с точностью до 1 %). Грань, которую не удалось построить, остаётся набором плоских треугольников; если не удаётся вся деталь, она целиком остаётся из треугольников, и фича показывает предупреждение.
- Поверхности ищутся с допуском в одну десятитысячную размера модели. Хорошо распознаются STL, выгруженные из CAD (вершины сетки лежат на гранях); сканы и сетки из скульптинга остаются треугольниками.
- Тор (желоб подшипника, скругление вокруг оси) распознаётся поясами конусов по рядам сетки. Свободные формы (лофт, протяжка по спирали, резьба) остаются треугольниками; тело больше 30 000 треугольников не распознаётся вовсе.
- Снимите флажок, чтобы оставить исходные треугольники (лежащие в одной плоскости всё равно сливаются в одну грань).

## Особенности {#details}

- Файл сохраняется внутри документа, поэтому документ и файл проекта увеличиваются на его размер. Повторно выбирать файл после перезагрузки не нужно.
- STL (двоичный и текстовый) разбивается на тела по общим рёбрам треугольников: каждое замкнутое тело становится деталью, незамкнутая сетка — поверхностью. Детали, которые в файле касаются друг друга по ребру или грани (например, сборка, сохранённая одним STL), остаются отдельными деталями.
- К импортированным деталям применимы любые фичи: скругления, отверстия, булевы операции и т. д.

> **Ограничение.** Поддерживаются только STEP и STL. Цвета и имена деталей из файла не переносятся.
