# Офлайн-работа и хранение

WebCAD работает без сервера и без учётной записи: геометрическое ядро (OpenCascade) выполняется прямо в браузере, а документы хранятся в его локальной базе данных.

## Офлайн-режим {#offline}

- При первом открытии собранного приложения (например, с `npm run build` и `npm run serve` или с веб-сервера) Service Worker сохраняет в кэш браузера всё приложение вместе с геометрическим ядром (WASM, около 23 МБ) и этой справкой.
- После этого WebCAD открывается и работает без сети. Его можно [установить как приложение](#install): оно откроется в отдельном окне.
- Обновления приложения загружаются, когда сеть снова доступна: пока сеть есть, страница берётся с сервера, так что новая версия открывается при обычном обновлении страницы (без сброса кеша).

> **Примечание.** В режиме разработки (`npm run dev`) Service Worker не используется — офлайн работает только собранная версия.

## Установка приложения {#install}

Установленный WebCAD открывается в отдельном окне без адресной строки, запускается с рабочего стола, из меню «Пуск», Dock или Launchpad и работает без сети.

- **Chrome и Edge.** Откройте **Настройки** (на странице документов или в редакторе) и выберите **Приложение → Установить приложение…**, затем подтвердите установку в окне браузера. Тот же пункт есть в адресной строке (значок установки) и в меню браузера.
- **Safari на Mac.** Выберите в меню **Файл → Добавить в Dock**.
- **Safari на iPhone и iPad.** Нажмите **Поделиться → На экран «Домой»**.
- **Firefox** на компьютере не устанавливает сайты как приложения.

Если в настройках вместо **Установить приложение…** показан пункт **Как установить приложение**, браузер не предлагает установку: он устанавливает сайты из своего меню (Safari), не умеет этого (Firefox) или приложение уже установлено. Тогда откройте его значком в адресной строке. В окне установленного приложения в настройках написано **Установлено как приложение**.

> **Примечание.** В Chrome и Edge приложение и сайт по тому же адресу используют одно хранилище: документы общие. Приложение, установленное из Safari, хранит данные отдельно от Safari. Перенесите в него документы через **Экспорт** в файл `.webcad.json` и **Импорт проекта**.

## Где хранятся документы {#storage}

- Документы, их миниатюры и незавершённые правки хранятся в **IndexedDB** этого браузера, отдельно для каждого адреса сайта. Никуда в сеть они не отправляются.
- Настройки интерфейса (язык, режим вращения, показ ограничений и выражений) хранятся в локальном хранилище браузера.
- WebCAD просит браузер сделать хранилище постоянным, чтобы данные не удалялись при нехватке места.

> **Внимание.** Документы не синхронизируются между браузерами, профилями и компьютерами. Если очистить данные сайта в браузере, документы будут удалены. Разные адреса (например, `localhost:5173` и `localhost:4173`) — это разные хранилища.

## Резервные копии и перенос {#backup}

- **Экспорт** на вкладке **Проект WebCAD** сохраняет документ целиком в файл `.webcad.json`.
- **Импорт проекта** на странице документов открывает такой файл в любом браузере.
- В Chrome и Edge документы можно держать в [папке на компьютере](documents#folder): их файлы `.webcad.json` обновляются при каждом сохранении.
- Геометрию для других программ сохраняйте в STEP — см. [Импорт и экспорт](import-export).
