# Измерения

Отдельного инструмента измерения нет: выберите элементы в графической области (или деталь в [списке деталей](parts)), и в правом нижнем углу графической области появится панель с результатами. Пока открыт диалог фичи или эскиз, панель скрыта.

```figure

```

## Что показывается {#values}

| Выбрано | Значения |
|---|---|
| Деталь | **Объём**, **Площадь поверхности**, **Масса**, **Центр масс** (X, Y, Z) |
| Грань | **Площадь**; для цилиндрической грани — также **Радиус** |
| Ребро | **Длина**; для окружности или дуги — также **Радиус** и **Диаметр** |
| Вершина или начало координат | Координаты **X**, **Y**, **Z** |
| Кривая эскиза | **Длина** |
| Два любых элемента | **Мин. расстояние** и его проекции **ΔX**, **ΔY**, **ΔZ**; **Макс. расстояние** — между самыми дальними точками |
| Две окружности, дуги, цилиндрические или сферические грани, вершины | **Между центрами**: между центрами окружностей и сфер, у цилиндров — между осями |
| Два ребра, грани или плоскости | **Угол** — острый угол между прямыми, между плоскостями или между прямой и плоскостью. У окружности направление — нормаль её плоскости, у цилиндра — ось |
| Несколько рёбер / граней / деталей | **Суммарная длина** / **Суммарная площадь** / **Суммарный объём** |

Длины показываются в единицах документа, углы — в градусах.

На модели оранжевым пунктиром показано минимальное расстояние. Щёлкните строку **Макс. расстояние** или **Между центрами** — пунктир покажет это расстояние, а строка отметится штрихом.

Максимальное расстояние между отрезками и плоскими гранями точное (оно всегда между вершинами), для кривых и изогнутых граней — по их точкам, с точностью до доли процента.

## Порядок действий {#steps}

1. Закройте диалог фичи или эскиз, если он открыт.
2. Щёлкните грань, ребро или вершину. Чтобы измерить расстояние, щёлкните второй элемент.
3. Прочитайте значения на панели. Щелчок по пустому месту (или `Esc`) снимает выбор.

> **Совет.** Чтобы быстро получить массу и объём детали, щёлкните правой кнопкой по любой её грани и выберите **Масс-характеристики** — будет выбрана вся деталь.

> **Ограничение.** Масса считается с плотностью 7,85 г/см³ (сталь); выбрать материал в интерфейсе пока нельзя.
