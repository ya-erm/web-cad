# Линия

Рисует отрезки прямых, по умолчанию — непрерывной цепочкой: конец одного отрезка становится началом следующего.

**Панель эскиза:** **Линия** · **Клавиша:** `L`

## Порядок действий {#steps}

1. Нажмите **Линия** (`L`).
2. Щёлкните начальную точку.
3. Щёлкайте следующие точки — каждый щелчок добавляет отрезок, соединённый с предыдущим.
4. Завершите цепочку: `Esc`, двойной щелчок, правый щелчок или `Enter`.

Цепочка завершается сама, если щёлкнуть по существующей точке или кривой (например, замкнуть контур на первой точке).

## Особенности {#details}

- Пока вы ведёте отрезок, рядом показывается его текущая длина.
- Если отрезок ведётся почти горизонтально или вертикально, рядом с курсором появляется значок горизонтальности или вертикальности, и линия получает это ограничение.
- Начало и конец, поставленные на точку, кривую, середину линии или начало координат, получают соответствующие ограничения (см. [Привязки](sketch#inference)). Захваченные точки позволяют выровнять конец отрезка с другой точкой.
- После каждого отрезка у него появляется поле [быстрого размера](sketch#quick-dimensions): наберите длину и нажмите `Enter` — цепочка продолжится от точки с новой длиной.
- Соседние отрезки цепочки соединены ограничением совпадения.
- С включённым режимом **Вспомогательная** (`Q`) линии создаются вспомогательными.
