# Концентричность

Делает общим центр двух окружностей, дуг или эллипсов.

**Панель эскиза:** **Концентричность** · **Клавиша:** `Shift+O`

```figure
image: ../images/constraint-concentric.svg
alt: Окружности с разными центрами получают общий центр
caption: Схема: 1 — до ограничения, 2 — после. Точное положение элементов зависит от остальных ограничений эскиза.
width: 600
```

## Что выбрать {#select}

Ровно два элемента из: окружности, дуги, эллипсы, точки. Точка совмещается с центром другой кривой. Иначе появится сообщение «Выберите две окружности или дуги».

## Как работает {#how}

- Центры сливаются в одну точку; радиусы не меняются.
- Обычно сдвигаются обе кривые — навстречу друг другу. Чтобы одна осталась на месте, сначала зафиксируйте её ([Фиксация](constraint-fix)) или задайте положение её центра размерами.

## Применение {#uses}

- Кольца, шайбы, ступенчатые валы в эскизе для [вращения](revolve).
- Отверстие по центру дуги скругления.

## Удаление {#delete}

Щёлкните значок ◎ рядом с кривой и нажмите `Del`.
