# Соединитель (mate connector)

Соединитель — локальная система координат, привязанная к геометрии модели. В графической области он показывается тройкой осей: X — красная, Y — зелёная, Z — синяя. Соединитель можно использовать как плоскость, ось, направление или точку в других фичах, а также чтобы совмещать детали фичей [Перемещение](transform#mates).

**Панель инструментов:** **Соединитель (mate connector)**

## Порядок действий {#steps}

1. Нажмите **Соединитель (mate connector)**.
2. Выберите режим: **На объекте** (по умолчанию) или [**Между объектами**](#between).
3. В поле **Расположение** наведите курсор на грань или ребро: появятся [точки привязки](#inference). Ближайшая к курсору подсвечивается оранжевым вместе с превью осей — щёлкните, чтобы поставить соединитель в неё.
4. При необходимости переориентируйте оси: **Основная ось (Z)**, **Вторая ось (X)**, **Развернуть основную ось**, **Переориентировать**, **Поворот вокруг Z**.
5. При необходимости сдвиньте соединитель: **Смещение X**, **Смещение Y**, **Смещение Z**.
6. Нажмите ✓ (`Enter`).

`F1` в любом поле диалога открывает эту страницу.

## Точки привязки {#inference}

Как в Onshape, при наведении на геометрию показываются точки, куда можно поставить соединитель:

| Наведение на | Точки | Ось Z |
|---|---|---|
| Плоскую грань | Центр грани, вершины, середины рёбер, центры дуг и отверстий | По нормали грани (соединитель параллелен грани) |
| Цилиндрическую, коническую или тороидальную грань (фаска и скругление круглого ребра) | На оси: начало, середина и конец грани | По оси |
| Сферическую грань | Центр сферы | По умолчанию (вдоль Z мира) |
| Прямое ребро | Начало, середина, конец | Вдоль ребра |
| Круговое ребро (отверстие, дуга) | Центр, начало, середина, конец | По оси окружности |
| Вершину | Сама вершина | По умолчанию (вдоль Z мира) |

Чтобы выбрать точку, которая лежит над другой гранью, держите `Shift`: точки последней грани или ребра остаются на экране, пока вы ведёте к ним курсор.

После выбора ребра или цилиндра под полем **Расположение** появляется переключатель **Центр / Начало / Середина / Конец** — им можно сменить точку без повторного выбора.

## Между объектами {#between}

В режиме **Между объектами** начало соединителя ставится посередине между двумя точками — например, между центрами отверстий на противоположных стенках или между гранью и концом штифта.

1. Включите **Между объектами**.
2. Выберите первую точку в поле **Расположение** — фокус сам перейдёт в поле **Второе расположение**.
3. Выберите вторую точку. У каждой из них свой переключатель **Центр / Начало / Середина / Конец**.

Ориентация осей берётся от первого расположения; дальше её можно менять как обычно.

## Расположение {#location}

| Выбрано | Начало соединителя | Ось Z |
|---|---|---|
| Вершина, точка эскиза, начало координат | В точке | По умолчанию |
| Прямое ребро, линия эскиза | В середине | Вдоль линии |
| Круговое ребро, окружность или дуга эскиза | В центре | По оси окружности |
| Плоская грань | В центре грани | По нормали грани |
| Цилиндрическая, коническая или тороидальная грань | На оси | По оси |
| Сферическая грань | В центре сферы | По умолчанию |
| Плоскость | В начале плоскости | По нормали плоскости |
| Другой соединитель | В его начале | Как у него |

## Параметры {#options}

| Поле | Описание |
|---|---|
| **На объекте / Между объектами** | Ставить начало в выбранную точку или [посередине между двумя точками](#between). |
| **Расположение** | Геометрия, к которой привязано начало (обязательно). |
| **Второе расположение** | Вторая точка в режиме **Между объектами**. |
| **Деталь-владелец** | Деталь, вместе с которой [движется соединитель](#owner). Если поле пустое — деталь, на которой выбрано расположение. |
| **Основная ось (Z)** | Направить ось Z вдоль выбранного элемента: прямого или кругового ребра, плоской или цилиндрической грани, плоскости, линии эскиза. |
| **Вторая ось (X)** | Повернуть ось X в сторону выбранного элемента (прямое ребро, плоская грань, плоскость, линия эскиза). |
| **Развернуть основную ось** | Направить Z в противоположную сторону. |
| **Переориентировать** | Повернуть соединитель так, чтобы основная ось (Z) легла вдоль прежней оси **X** или **Y** (**Z** — без изменений). |
| **Поворот вокруг Z** | Повернуть оси X и Y вокруг Z на заданный угол. |
| **Смещение X**, **Смещение Y**, **Смещение Z** | Сдвинуть начало вдоль собственных осей соединителя. |

## Деталь-владелец {#owner}

Соединитель принадлежит детали: если ниже в списке фич [Перемещение](transform) двигает или поворачивает эту деталь, соединитель перемещается вместе с ней. Так, после **От соединителя к соединителю** перемещённый соединитель совпадает с целевым.

- По умолчанию владелец — деталь, на грани, ребре или вершине которой стоит соединитель. Соединитель на другом соединителе наследует его владельца.
- У соединителя в начале координат, на плоскости или эскизе владельца нет — он остаётся на месте. Чтобы он двигался с деталью, выберите её в поле **Деталь-владелец**.
- Копии деталей (флажок **Копировать деталь** в перемещении) соединители не переносят.

## Где использовать {#use}

- **Как плоскость** (плоскость XY соединителя, нормаль — Z): плоскость [эскиза](sketch), [плоскость отражения](mirror), режущая плоскость [разделения](split), основа [плоскости со смещением](plane), окончание [выдавливания](extrude) **До грани**.
- **Как ось** (ось Z): [вращение](revolve), [круговой массив](circular-pattern), поворот в [перемещении](transform), [спираль](helix).
- **Как направление** (ось Z): [линейный массив](linear-pattern), сдвиг вдоль элемента в [перемещении](transform).
- **Как точка** (начало).
- **Для совмещения деталей:** [Перемещение](transform#mates) → **От соединителя к соединителю**.

Соединитель можно скрыть значком глаза в [списке фич](feature-list).

В [сборке](assembly-mates#mates) соединители детали показываются на её экземплярах и служат опорами для сопряжений.
