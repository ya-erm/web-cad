# Массивы в эскизе

Линейный и круговой массивы копируют выбранные элементы эскиза. Массивы **ассоциативны**: копии строятся из исходных элементов («затравки») при каждом решении эскиза, поэтому повторяют любые изменения оригинала.

## Линейный массив {#linear}

1. В режиме выбора выберите элементы.
2. Нажмите **Линейный массив в эскизе**. Появятся копии и панель параметров.
3. Задайте **Количество** (вместе с оригиналом), **Расстояние** (шаг) и **Угол направления** (кнопки → ↑ ← ↓ задают 0°, 90°, 180°, 270°).
4. Для сетки включите **Второе направление** (перпендикулярно первому) и задайте его **Количество** и **Расстояние**.
5. Нажмите ✓ (`Enter`) или щёлкните пустое место. ✕ (`Esc`) отменяет массив.

В графической области шаг и направление можно менять, перетаскивая стрелку от затравки. Двойной щелчок по значку количества или шага открывает поле для ввода значения.

## Круговой массив {#circular}

1. Выберите элементы. Чтобы задать центр массива, выберите **последней** точку эскиза (например, центр окружности) — центр будет привязан к ней.
2. Нажмите **Круговой массив в эскизе**.
3. Задайте **Количество**. Флажок **Полный круг (равный шаг)** раскладывает копии равномерно по окружности; без него задайте **Угол** — общий угол массива.
4. Центр без привязки можно перетащить за значок в графической области; если отпустить его на точке, центр привяжется к ней.
5. Нажмите ✓ (`Enter`).

## Изменение и удаление {#edit}

- Двойной щелчок по копии или по метке «N×» рядом с затравкой открывает параметры массива.
- Правый щелчок по копии: **Изменить массив**, **Удалить копию**, **Удалить массив**.
- Удалённая копия оставляет «пропуск»; число пропусков показано на панели («удалено копий: N»). Пропуски сохраняются при изменении количества.
- Кнопка **Удалить массив** на панели удаляет все копии (затравка остаётся).

## Особенности {#details}

- Во все поля можно вводить выражения и [переменные](variables), например `#n` или `#pitch * 2`.
- Копии не имеют собственных ограничений, к ним нельзя привязываться и ставить на них размеры — управляйте затравкой и параметрами массива.
- Копии образуют области и участвуют в фичах наравне с обычной геометрией.
- В массиве не более 500 копий.
