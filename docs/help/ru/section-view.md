# Сечение

**Сечение** временно рассекает детали плоскостью, чтобы заглянуть внутрь модели: часть по одну сторону плоскости скрывается, а поверхности разреза закрашиваются темнее. Модель при этом не меняется — это только режим отображения.

## Порядок действий {#steps}

1. При желании выберите плоскую грань или плоскость, по которой нужно резать.
2. Нажмите **Сечение** в меню вида (под кубом видов). Если была выбрана плоская грань или плоскость, сечение строится по ней (**Выбранная**), иначе — по плоскости **Front**.
3. На панели **Сечение** выберите плоскость: **Top**, **Front**, **Right** или **Выбранная** (кнопка доступна, когда выбрана плоская грань или плоскость).
4. Передвиньте ползунок или введите **смещение** вдоль нормали плоскости в поле справа от ползунка (в единицах документа, `Enter` — применить).
5. Флажок **Оставить другую сторону** показывает противоположную половину модели.
6. Закройте сечение крестиком на панели или повторным нажатием кнопки **Сечение**.

## Особенности {#notes}

- Сечение действует только на детали; эскизы и плоскости показываются как обычно.
- Отрезанную часть модели нельзя выбрать щелчком.
- Сечение не сохраняется в документе и не попадает в экспорт и чертежи.

> **Примечание.** Сечением можно управлять и из [Agent API](agent-api): `npm run agent -- call section '{"plane":"front","offset":5}'`.
