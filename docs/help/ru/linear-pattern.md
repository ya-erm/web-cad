# Линейный массив

Копирует детали или фичи вдоль одного или двух направлений с постоянным шагом.

**Панель инструментов:** **Линейный массив**

## Порядок действий {#steps}

1. Нажмите **Линейный массив**.
2. Выберите тип: **Массив деталей** или **Массив фич**.
3. Выберите детали (в графической области или списке деталей) либо отметьте фичи в списке **Фичи для массива**.
4. Щёлкните поле **Направление** и выберите линию эскиза, прямое ребро, плоскую грань или плоскость (направление — их нормаль), цилиндрическую грань или круговое ребро (направление — их ось).
5. Задайте **Расстояние** (шаг) и **Количество**. Кнопка рядом с расстоянием разворачивает направление.
6. Для сетки включите **Второе направление** и задайте его направление, расстояние и количество.
7. Нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Массив деталей** / **Массив фич** | Что копировать. |
| **Детали для массива** | Для массива деталей. |
| **Фичи для массива** | Для массива фич: список фич выше текущей, создающих или вырезающих тела (выдавливание, вращение, сдвиг, лофт, отверстие, утолщение). |
| **Направление** | Направление первого ряда. |
| **Расстояние** | Шаг между копиями (по умолчанию 20 мм). |
| **Количество** | Число экземпляров вместе с оригиналом (по умолчанию 3). |
| **Второе направление** | Включает второй ряд: **Направление**, **Расстояние**, **Количество**. |
| **Новая** / **Добавить** | Для массива деталей: копии — отдельные детали или объединяются с оригиналом. |

## Массив фич {#feature-pattern}

Массив фич повторяет результат выбранных фич в новых местах с той же операцией: копии выреза вырезают, копии бобышки добавляют материал (объединяясь со всеми деталями). Так удобно размножить отверстие или паз на детали.

> **Ограничение.** Массив граней пока не поддерживается — используйте массив фич.
