# Угол

Задаёт угол между двумя линиями.

**Панель эскиза:** **Размер** · **Клавиша:** `D`

```figure

alt: Угол 48° между двумя линиями

```

## Порядок действий {#steps}

1. Нажмите **Размер** (`D`).
2. Щёлкните две непараллельные линии (если линии параллельны, получится [расстояние](dimension-distance#kinds)).
3. Щёлкните между линиями, где поставить надпись.
4. Введите угол и нажмите `Enter`.

## Как работает {#how}

- Задаётся угол между направлениями линий; линии не обязаны иметь общую точку.
- Сохраняется направление поворота: если вторая линия отклонена от первой против часовой стрелки, она останется отклонённой в ту же сторону.
- Поворачиваются обе линии, каждая на часть изменения. Чтобы одна осталась на месте, сделайте её горизонтальной или вертикальной либо зафиксируйте.

## Значения {#values}

- Число без единиц — градусы: `30`.
- С единицами: `30 deg`, `0.5 rad`, выражения: `90 deg - #a`, `360 deg / #n`.
- Для прямого угла удобнее ограничение [Перпендикулярность](constraint-perpendicular), для 0° — [Параллельность](constraint-parallel).
