# Управление видом

## Мышь {#mouse}

| Действие | Мышь |
|---|---|
| Вращение | Правая кнопка + перетаскивание |
| Панорама (сдвиг) | Средняя кнопка + перетаскивание или `Ctrl` + правая кнопка + перетаскивание |
| Масштаб | Колесо мыши — приближение к точке под курсором |
| Показать всё | Двойной щелчок средней кнопкой |
| Выбор | Левая кнопка |
| Контекстное меню | Щелчок правой кнопкой без перемещения |

Вращение происходит вокруг точки детали под курсором (если под курсором нет детали — вокруг центра вида). Способ вращения выбирается в **Настройки** → **Вращение**:

- **Свободное** — модель вращается вокруг осей экрана (как в Onshape);
- **Вокруг вертикали (Z вверх)** — вращение вокруг оси Z, горизонт не заваливается.

## Куб видов {#view-cube}

Куб в правом верхнем углу графической области поворачивается вместе с моделью. Щелчок по грани куба (**Front**, **Top**, **Right** и т. д.) показывает модель с этой стороны, щелчок по ребру или углу — под углом.

- **Перетаскивание куба** левой или правой кнопкой вращает вид, как перетаскивание правой кнопкой в графической области (вокруг центра вида; режим вращения из **Настроек** действует и здесь).
- **Правый щелчок по кубу** (без перетаскивания) открывает меню: стандартные виды, изометрия, диметрия, триметрия, **Показать всё** (`F`) и **Перспектива**.

Кнопки под кубом видов:

| Кнопка | Что делает |
|---|---|
| **Показать всё** (`F`) | Масштабирует вид так, чтобы поместилась вся модель. |
| **Вид по нормали** (`N`) | В эскизе — смотрит перпендикулярно плоскости эскиза; если выбрана плоская грань или плоскость — перпендикулярно ей; иначе — вид сверху. |
| **Сечение** | Рассекает модель плоскостью, см. [Сечение](section-view). |
| **Виды** | Стандартные виды, перспектива и видимость вспомогательных объектов (см. ниже). |

Меню **Виды**:

| Пункт | Клавиши |
|---|---|
| **Front**, **Back**, **Left**, **Right**, **Top**, **Bottom** | `Shift+1` … `Shift+6` |
| **Изометрия**, **Диметрия**, **Триметрия** (отдельной группой) | Изометрия — также `Shift+7` (в меню клавиша не показана) |
| **Перспектива** | Переключает перспективную проекцию (по умолчанию — ортогональная). |
| **Показывать плоскости** | `P` — показать или скрыть плоскости |
| **Показывать эскизы** | `Shift+H` — показать или скрыть все эскизы |

## Клавиатура {#keyboard}

| Клавиши | Действие |
|---|---|
| `←` `→` | Повернуть вид на 15° вокруг вертикали |
| `↑` `↓` | Повернуть вид на 15° вокруг горизонтали |
| `Shift` + стрелка | Повернуть на 90° |
| `Shift+Z` | Приблизить |
| `Z` | Отдалить |
| `F` | Показать всё |
| `N` | Вид по нормали |

Отдельные плоскости, эскизы и спирали можно скрыть значком глаза в [списке фич](feature-list), детали — в [списке деталей](parts).
