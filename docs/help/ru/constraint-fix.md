# Фиксация

Закрепляет элементы эскиза в их текущем положении.

**Панель эскиза:** **Фиксация** · **Клавиша:** `Shift+J`

```figure
image: ../images/constraint-fix.svg
alt: Свободная синяя линия становится зафиксированной чёрной
caption: Схема: 1 — до ограничения, 2 — после. Точное положение элементов зависит от остальных ограничений эскиза.
width: 600
```

## Что выбрать {#select}

Один или несколько любых элементов: точки, линии, окружности, дуги, эллипсы, сплайны. Если ничего не выбрано — «Выберите элементы для фиксации».

## Как работает {#how}

- Все параметры элемента замораживаются: координаты точек, для окружности — центр и радиус, для линии — оба конца.
- Зафиксированный элемент полностью определён и показывается чёрным; другие ограничения больше не могут его сдвинуть — двигаться будут остальные элементы.

## Где возникает автоматически {#auto}

- Точка, поставленная в начало координат (привязка к началу координат), фиксируется в нём.
- Геометрия, [спроецированная](sketch-use) инструментом **Проецировать**, зафиксирована (её положение берётся из источника).

## Применение {#uses}

- «Опорный» элемент, относительно которого строится остальной эскиз, например при обрисовке по [проецированной](sketch-use) геометрии.
- Временная фиксация, чтобы при наложении других ограничений сдвигалась нужная часть эскиза.

> **Совет.** Для параметрических эскизов лучше задавать положение [размерами](sketch-dimensions) от начала координат: фиксация запоминает числа, которые потом нельзя изменить выражением.

## Удаление {#delete}

Щёлкните значок якоря у элемента и нажмите `Del` — элемент снова можно перемещать.
