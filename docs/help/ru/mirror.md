# Зеркало

Создаёт зеркальную копию деталей или фич относительно плоскости.

**Панель инструментов:** **Зеркало**

## Порядок действий {#steps}

1. Нажмите **Зеркало**.
2. Выберите **Массив деталей** или **Массив фич** и укажите, что отражать.
3. Щёлкните поле **Плоскость отражения** и выберите плоскость или плоскую грань.
4. Нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Массив деталей** / **Массив фич** | Отражать детали целиком или результат выбранных фич. |
| **Детали для отражения** / **Фичи для отражения** | Что отражать. |
| **Плоскость отражения** | Плоскость (**Top**, **Front**, **Right**, [Плоскость](plane)) или плоская грань. |
| **Новая** / **Добавить** | Для деталей: отражённая копия — отдельная деталь или объединяется с оригиналом. |

> **Совет.** Чтобы построить симметричную деталь, смоделируйте половину и отразите её с операцией **Добавить** относительно плоскости симметрии.
