# Переменная

Фича **Переменная** задаёт именованное значение, которое можно использовать в любом числовом поле и размере эскиза ниже по истории: `#имя`. Обзор работы с переменными и синтаксис выражений — на странице [Переменные и выражения](variables).

**Панель инструментов:** **Переменная** · также кнопка **+** в **Таблице переменных**


## Порядок действий {#steps}

1. Поставьте полосу отката туда, где переменная должна появиться (обычно в начало).
2. Нажмите **Переменная**.
3. Выберите тип, введите имя и значение, нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Длина** / **Угол** / **Число** / **Любое** | Тип значения. Для **Длина** число без единиц понимается в единицах документа, для **Угол** — в градусах. **Любое** сохраняет единицы выражения как есть. |
| **Имя** | Имя без `#`: латинские буквы, цифры и `_`, начинается с буквы или `_` (например, `width`, `wall_t`). |
| **Значение** | Число или выражение, может ссылаться на переменные выше: `#width / 2 + 3 mm`. |
| **Описание** | Необязательный комментарий; показывается во всплывающей подсказке в таблице переменных. |

## Особенности {#details}

- В списке фич рядом с именем фичи показывается `#имя = значение`.
- Переменная видна только фичам ниже неё. Подавленная переменная не действует.
- Если имя недопустимо или выражение с ошибкой, фича отмечается красной точкой («Invalid variable name» и т. п.).
