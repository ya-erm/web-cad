# Оболочка

Делает деталь полой со стенками заданной толщины. Выбранные грани удаляются — получается открытый корпус.

**Панель инструментов:** **Оболочка**

## Порядок действий {#steps}

1. Нажмите **Оболочка**.
2. Выберите грани, которые нужно удалить (например, верхнюю грань коробки). Чтобы получить закрытую полую деталь без отверстий, выберите саму деталь в [списке деталей](parts).
3. Задайте **Толщина**, нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Удаляемые грани** | Грани, которые станут открытыми; или деталь целиком — для закрытой оболочки. |
| **Толщина** | Толщина стенок (по умолчанию 2 мм). |
| **Оболочка наружу** | Стенки наращиваются снаружи исходной поверхности, внутренний объём сохраняет размеры детали. |

Сообщение «Оболочка не построена: возможно, толщина слишком большая» означает, что стенка не помещается (например, толщина больше радиуса скругления).
