# Детали и внешний вид

Деталь — это отдельное твёрдое тело Part Studio. Детали создаются фичами с операцией **Новая** ([Выдавливание](extrude), [Вращение](revolve) и др.), [импортом](import), [массивами](linear-pattern) и [разделением](split). По умолчанию они называются **Part 1**, **Part 2** и т. д.

## Список деталей {#parts-list}

Список **Детали** находится под списком фич. В заголовке — количество деталей.

- Щелчок выбирает деталь (повторный — снимает выбор). Для одной выбранной детали [панель измерений](measure) показывает объём, площадь поверхности, массу и центр масс.
- При наведении курсора деталь подсвечивается в графической области.
- Двойной щелчок — переименовать (`Enter` — сохранить, `Esc` — отменить).
- Значок глаза справа в строке скрывает или показывает деталь: он появляется при наведении, а нажимать можно в любом месте правого края строки.
- Глаз в заголовке **Детали** скрывает сразу все детали (и поверхности), если хоть одна видна, и показывает все, если скрыты все. Это один шаг отмены.

## Контекстное меню {#context-menu}

```figure
image: ../images/parts-menu.png
alt: Контекстное меню детали с видимостью, экспортом и палитрой цветов
caption: Меню относится к выбранной детали (или ко всем выбранным). Палитра меняет её цвет; «Скрыть» меняет только видимость.
width: 350
```

Правый щелчок по детали в списке. Если выбрано несколько деталей (щелчками по строкам) и щёлкнуть одну из них, меню относится ко всем выбранным, кроме **Переименовать**: пункты называются **Экспорт деталей** и **Удалить детали**.

| Пункт | Что делает |
|---|---|
| **Переименовать** | Меняет имя детали. |
| **Скрыть** / **Показать** | Видимость детали (выбранных деталей). |
| **Скрыть остальные** | Оставляет видимой только эту деталь (выбранные детали). |
| **Показать все** | Показывает все детали. |
| **Материал…** | Материал детали (или всех выбранных) из библиотеки или свой — по его плотности считается масса, см. [Измерения](measure#material). |
| **Экспорт детали** / **Экспорт деталей** | Открывает диалог экспорта для этой детали или всех выбранных, см. [Импорт и экспорт](import-export). |
| **Удалить деталь** / **Удалить детали** | Добавляет в историю фичу [Удалить деталь](delete-part) — одну на все выбранные детали. |
| **Изменить цвет** | Палитра из 20 цветов и **Свой цвет…** для любого цвета (всем выбранным деталям). |
| **Непрозрачность** | Ползунок под палитрой, 10–100 %: полупрозрачная деталь показывает то, что внутри неё и за ней. Перетаскивание — один шаг отмены; на массу и экспорт не влияет. |

Цвет, непрозрачность, имя и видимость хранятся в документе. Цвет сохраняется при экспорте в 3MF.

Скрыть деталь можно и из графической области: правый щелчок по её грани или ребру → **Скрыть**.

> **Ограничение.** Материал детали пока не задаётся в интерфейсе: масса считается с плотностью 7,85 г/см³ (сталь).
