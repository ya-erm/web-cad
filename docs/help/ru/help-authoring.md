# Как устроена справка

Эта страница — для тех, кто дополняет справку WebCAD вместе с новыми возможностями.

## Где лежат файлы {#files}

| Путь | Что там |
|---|---|
| `docs/help/toc.json` | Содержание: разделы, страницы и подстраницы, их заголовки на каждом языке, значки, языки и порядок замены. |
| `docs/help/<язык>/<id>.md` | Текст страницы. Имя файла — идентификатор страницы, одинаковый во всех языках. |
| `docs/help/images/` | Снимки экрана и рисунки (общие для всех языков). |
| `docs/help/images/<язык>/` | Снимки интерфейса на этом языке: файл с тем же именем заменяет общий для страниц этого языка. |
| `src/help/` | Просмотрщик справки, разбор Markdown, поиск, контекстная справка (`pages.ts`). |

Справка встраивается в сборку и работает офлайн; страницы загружаются по мере открытия.

## Добавить страницу {#add-page}

1. Создайте `docs/help/ru/<id>.md` и `docs/help/en/<id>.md`; первая строка — заголовок `# …`.
2. Добавьте страницу в `docs/help/toc.json`: `{ "id": "<id>", "icon": "<значок>", "title": { "ru": "…", "en": "…" } }`. Подстраницы задаются полем `"children"`.
3. Для фичи или инструмента эскиза пропишите страницу в `src/help/pages.ts` — тогда её откроют кнопка **?** в диалоге и клавиша `F1`.
4. Запустите `npx vitest run src/help` — тест проверит, что страница есть во всех обязательных языках, а ссылки, якоря и картинки находятся.

## Добавить язык {#add-language}

1. Создайте папку `docs/help/<код>/` (например, `de`) и переведите страницы. Непереведённые страницы автоматически показываются на английском, затем на русском, с пометкой.
2. Добавьте язык в `"languages"` в `toc.json` и заголовки `"<код>": "…"` у разделов и страниц.
3. При желании переведите надписи самого просмотрщика в `src/help/strings.ts`.

## Разметка {#markup}

- Ссылка на другую страницу — по её идентификатору: `[Линия](sketch-line)`, с якорем — `[Касательная дуга](sketch-arc#tangent)`.
- Стабильные якоря разделов задаются в заголовке: `## Параметры {#options}` — одинаково во всех языках.
- Клавиши пишутся как код: `` `Shift+S` `` — справка покажет их как клавиши.
- Заметки: строка в цитате, начинающаяся с жирного слова: `> **Совет.** …`, `> **Примечание.** …`, `> **Ограничение.** …`.
- Таблицы, нумерованные и маркированные списки, блоки кода — как в обычном Markdown.
- Снимок экрана с номерами-метками — блок `figure`: путь к картинке, подпись, ширина и строки «номер, X %, Y %, подсказка». Метки рисуются поверх картинки, поэтому один снимок подходит для всех языков:

````text
```figure
image: ../images/interface-part-studio.jpg
alt: Окно Part Studio
1 50% 1.8% Верхняя панель
```
````

Снимки делайте в небольшом размере (до ~1600 px по ширине, JPEG или PNG), обрезая их до нужной области.

## Как выбрать иллюстрацию {#illustrations}

- **Диалог или панель:** снимайте реальное приложение, оставляя только нужные элементы и немного контекста. Текст полей должен читаться без увеличения всей страницы.
- **Геометрическое правило:** используйте SVG-схему, чтобы линии, значки и размеры оставались чёткими при увеличении. В подписи явно называйте её схемой, если она упрощает поведение решателя.
- **Изменение геометрии:** показывайте «до / после» в одной схеме или в таблице из двух изображений с сопоставимым масштабом.
- **Порядок щелчков:** пронумеруйте точки и объясните каждый номер в подписи. Шаги инструкции должны идти подряд, без больших картинок между пунктами.
- **Подпись и alt:** опишите, что нужно заметить и какие параметры использованы. Не оставляйте в снимке выделение или подсветку, не относящиеся к примеру.
- **Короткий справочник:** картинка не обязательна. Таблица форматов, клавиш или действий часто полезнее декоративного снимка.

Общие изображения хранятся в `images/`, а подписи и `alt` переводятся на каждой странице. На снимках интерфейса текст на языке интерфейса, поэтому для них есть языковые копии: страница на английском берёт `images/en/<имя>`, если такой файл есть, иначе общий `images/<имя>`. Ссылка в тексте одна и та же — `../images/<имя>`. Английские снимки снимаются в чистом профиле браузера с английским интерфейсом, в тех же кадрах, что и общие. Иллюстрации можно открыть щелчком в полном размере. После замены снимка проверьте координаты всех номерных меток и обе языковые версии в браузере.
