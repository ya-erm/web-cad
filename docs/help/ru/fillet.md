# Скругление

Скругляет рёбра детали дугой заданного радиуса.

**Панель инструментов:** **Скругление** · **Клавиши:** `Shift+F`

| До скругления | Радиус 3 мм |
|---|---|
| ![Пластина с острыми вертикальными рёбрами](../images/plate-before.png) | ![Четыре вертикальных ребра пластины скруглены радиусом 3 мм](../images/first-part-fillet.png) |

## Порядок действий {#steps}

1. Выберите рёбра или грани (выбор грани скругляет все её рёбра).
2. Нажмите **Скругление** (`Shift+F`).
3. Задайте **Радиус**, нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Постоянный радиус** / **Переменный радиус** | Один радиус по всей длине или свой в отдельных вершинах, см. [ниже](#variable). |
| **Рёбра и грани для скругления** | Рёбра; грань означает все её рёбра. Можно выбирать рёбра разных деталей. |
| **Радиус** | Радиус скругления (по умолчанию 2 мм); у переменного — в вершинах без своего радиуса. |
| **Вершины со своим радиусом**, **Вершина 1**, **Вершина 2**… | Для **Переменного радиуса**: вершины выбранных рёбер и радиус в каждой. |
| **Плавный переход** | Для **Переменного радиуса**: радиус меняется плавно, без излома в вершинах; иначе — линейно вдоль каждого ребра. |
| **Распространение по касательной** | Скругление продолжается на рёбра, гладко продолжающие выбранные (например, через уже скруглённый угол). См. [ниже](#tangent). |

## Переменный радиус {#variable}

Как Variable fillet в Onshape: радиус меняется вдоль ребра от значения в одной его вершине до значения в другой.

1. Выберите **Переменный радиус** и рёбра.
2. Щёлкните поле **Вершины со своим радиусом** и выберите в графической области концы рёбер.
3. У каждой вершины появится строка **Вершина 1**, **Вершина 2**… — задайте в ней радиус. Вершины без своего радиуса берут общий **Радиус**.
4. **Плавный переход** делает изменение радиуса плавным (в вершинах он выходит на постоянное значение), так что на цепочке рёбер нет изломов.

Убранная из выбора вершина забирает свой радиус с собой. Радиус в каждой вершине должен быть больше нуля.

## Советы {#tips}

- Сообщение «Скругление не построено: возможно, радиус слишком большой» обычно значит, что радиус больше соседних граней — уменьшите его.
- Скругления лучше ставить ближе к концу истории: тогда они меньше мешают выбору рёбер в других фичах.

## Распространение по касательной {#tangent}

Рёбра, гладко продолжающие выбранное (например, верхние рёбра коробки, сходящиеся через скруглённый угол, или рёбра паза), образуют одну цепочку. С включённым флажком **Распространение по касательной** (по умолчанию) скругление и [фаска](chamfer) проходят её целиком.

Снимите флажок — и скругление останется только на выбранных рёбрах, как в Onshape: у конца выбранного ребра, где начинается невыбранное касательное, оно обрывается плоским торцом, перпендикулярным ребру, а соседнее ребро остаётся острым. Так можно скруглить, например, одну прямую сторону паза без его дуг или только дугу. Это работает и для вогнутых рёбер (скругление добавляет материал) и для фаски.

Если обрезать скругление по выбранным рёбрам не удалось, фича строится по всей цепочке и показывает жёлтое предупреждение «Касательные к выбранным рёбра тоже включены: остановить скругление на выбранных рёбрах не удалось».

> **Ограничение.** Точки со своим радиусом внутри ребра (не в вершинах), коническое сечение и скругление между гранями пока не поддерживаются.
