# Удалить деталь

Удаляет детали из модели начиная с этого места истории. Это фича: детали остаются в предыдущих шагах, а удаление можно отменить, подавив или удалив фичу.

**Панель инструментов:** **Удалить деталь** · также пункт **Удалить деталь** в контекстном меню [списка деталей](parts).

## Порядок действий {#steps}

1. Нажмите **Удалить деталь**.
2. В поле **Удаляемые детали** выберите детали.
3. Нажмите ✓ (`Enter`).

> **Совет.** Чтобы деталь просто не мешала, её можно скрыть значком глаза в списке деталей — это не меняет историю.

| Действие | Что изменится |
|---|---|
| **Скрыть** деталь | Только видимость. Геометрия остаётся в модели и доступна следующим фичам. |
| **Удалить деталь** | Добавится новая фича. Начиная с неё тела не будет; более ранние шаги сохраняются. |
| **Удалить** фичу в списке фич | Удалится сам шаг построения. Зависящие от него фичи могут перестать строиться. |
