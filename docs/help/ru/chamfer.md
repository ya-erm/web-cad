# Фаска

Срезает рёбра детали плоской фаской.

**Панель инструментов:** **Фаска**

## Порядок действий {#steps}

1. Выберите рёбра или грани (грань означает все её рёбра).
2. Нажмите **Фаска**.
3. Выберите **Тип фаски** и задайте размеры, нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Рёбра и грани для фаски** | Рёбра; грань означает все её рёбра. |
| **Тип фаски** | **Равные расстояния** — одинаковый катет на обеих гранях; **Два расстояния** — разные катеты; **Расстояние и угол** — катет и угол. |
| **Расстояние** | Катет фаски (по умолчанию 2 мм). |
| **Расстояние 2** | Второй катет для **Два расстояния**. |
| **Угол** | Угол для **Расстояние и угол** (по умолчанию 45°). |
| **Противоположное направление** | Для несимметричных фасок: меняет грань, от которой отсчитывается первое расстояние. |
| **Распространение по касательной** | Фаска продолжается на гладко сопряжённые рёбра. |

Сообщение «Фаска не построена: возможно, расстояние слишком большое» означает, что фаска не помещается на соседних гранях.

Как и скругление, фаска с включённым флажком **Распространение по касательной** продолжается на рёбра, гладко продолжающие выбранные, а со снятым — остаётся только на выбранных рёбрах, — см. [Скругление: распространение по касательной](fillet#tangent).
