# Круговой массив

Копирует детали или фичи по окружности вокруг оси.

**Панель инструментов:** **Круговой массив**

## Порядок действий {#steps}

1. Нажмите **Круговой массив**.
2. Выберите **Массив деталей** или **Массив фич** и укажите, что копировать.
3. Щёлкните поле **Ось** и выберите линию эскиза, прямое ребро, круговое ребро или цилиндрическую грань (используется их ось).
4. Задайте **Угол** и **Количество**, нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Массив деталей** / **Массив фич** | Что копировать, см. [Линейный массив](linear-pattern#feature-pattern). |
| **Детали для массива** / **Фичи для массива** | Исходные детали или фичи. |
| **Ось** | Ось вращения копий. |
| **Угол** | Общий угол массива (по умолчанию 360°). Кнопка рядом меняет направление. |
| **Количество** | Число экземпляров вместе с оригиналом (по умолчанию 4). |
| **Равномерно** | Копии распределяются по **Угол**: при 360° — равномерно по кругу, иначе первая и последняя копии стоят на краях угла. Без флажка **Угол** — это шаг между соседними копиями. |
| **Новая** / **Добавить** | Для массива деталей: отдельные детали или объединение с оригиналом. |
