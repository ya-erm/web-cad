# Утолщение

Превращает области эскиза или грани деталей в тело заданной толщины.

**Панель инструментов:** **Утолщение**

## Порядок действий {#steps}

1. Нажмите **Утолщение**.
2. В поле **Грани, поверхности и области эскиза** выберите области эскиза, грани (плоские или криволинейные) или поверхности.
3. Задайте **Толщина**; кнопка рядом меняет сторону.
4. Нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Новая** / **Добавить** / **Вычесть** / **Пересечь** | Тип операции. |
| **Грани, поверхности и области эскиза** | Области эскизов, грани деталей и [поверхности](offset-surface#thicken) целиком: у поверхности утолщаются все грани, а углы между плоскими гранями заполняются — получается одно тело. |
| **Толщина** | Толщина тела (по умолчанию 2 мм). Плоские области и грани утолщаются по нормали, криволинейные грани — эквидистантно. |
| **Объединить со всеми** / **Область объединения** | С какими деталями выполнять операцию (кроме **Новая**). |

> **Совет.** Чтобы получить пластину по эскизу, утолщение и [выдавливание](extrude) на ту же глубину дают одинаковый результат; утолщение удобнее для граней существующих деталей.
