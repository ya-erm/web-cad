# Переменные и выражения

Переменные делают модель параметрической: размер задаётся один раз, а используется в эскизах и фичах. Изменили переменную — перестроилось всё, что от неё зависит.

## Создание переменной {#create}

1. Поставьте [полосу отката](feature-list#rollback) туда, где переменная должна появиться (обычно — в начало истории).
2. Нажмите **Переменная** на панели инструментов (или **Добавить переменную** в таблице переменных).
3. Выберите тип, введите **Имя** и **Значение**, при желании — **Описание**.
4. Нажмите ✓ (`Enter`).

Переменная видна только фичам, которые стоят **ниже** неё в списке фич. Подробно о диалоге — на странице [Переменная](variable).

## Использование {#use}

Введите `#имя` в любое числовое поле диалога фичи или в [размер эскиза](sketch-dimensions):

- `#width`
- `#width / 2`
- `#d + 2 * #wall`

Как только вы наберёте `#`, под полем появится список доступных переменных с их значениями; следующие буквы сужают его (сначала имена, которые с них начинаются, потом те, что их содержат). `↑` и `↓` выбирают переменную, `Enter` или `Tab` вставляют её имя, `Esc` закрывает список; щелчок по строке тоже вставляет имя.

Размер эскиза, заданный выражением, отмечается значком **fx**.

## Таблица переменных {#table}

Кнопка **Таблица переменных** (под меню вида в правом верхнем углу графической области) открывает список всех переменных Part Studio:

```figure

```

| Столбец | Содержимое |
|---|---|
| **Имя** | `#имя` переменной. |
| **Значение** | Вычисленное значение в единицах документа (красным — если выражение с ошибкой). |
| **Выражение** | Щёлкните, чтобы изменить выражение прямо в таблице: `Enter` — применить, `Esc` — отменить. |

- Двойной щелчок по строке открывает диалог переменной.
- Кнопка **+** (**Добавить переменную**) вставляет новую переменную в позицию полосы отката и открывает её диалог.
- Переменные ниже полосы отката и отключённые переменные показаны бледнее.
- Таблица открывается слева от своей кнопки. Её можно перетащить за заголовок в любое место графической области — там она и будет открываться дальше; двойной щелчок по заголовку возвращает её к кнопке.

## Выражения {#expressions}

Выражения работают в любом числовом поле, в размерах эскиза, в параметрах массивов эскиза и в значениях переменных.

| Что | Примеры |
|---|---|
| Числа | `10`, `2.5`, `.5`, `1e3` |
| Единицы длины | `mm`, `cm`, `m`, `in`, `ft`, `yd`, `um` (также `millimeter`, `meter`, `inch`, `foot`) |
| Единицы углов | `deg`, `rad`, `°` (также `degree`, `radian`) |
| Операции | `+`, `-`, `*`, `/`, `^` (степень), скобки |
| Функции | `sqrt`, `abs`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, `min`, `max`, `floor`, `ceil`, `round` |
| Константа | `pi` (или `PI`) |
| Переменные | `#имя` |

Правила:

- Число без единиц длины понимается в единицах документа, угол без единиц — в градусах.
- Число без единиц можно прибавить к величине с единицами: `10 + 5 mm` = 15 мм.
- Складывать длину с углом нельзя: `10 mm + 5 deg` — ошибка «Mismatched units».
- `sin`, `cos`, `tan` принимают угол; число без единиц считается градусами.
- Неверное выражение подсвечивается красным, и поле не применяется.

## Примеры {#examples}

| Выражение | Значение |
|---|---|
| `1 in + 3 mm` | 28,4 мм |
| `#width / 2` | половина ширины |
| `sqrt(#a^2 + #b^2)` | гипотенуза |
| `360 deg / #n` | угловой шаг для `#n` копий |
| `max(#t, 2 mm)` | не меньше 2 мм |
