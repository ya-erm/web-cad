# Agent API

Agent API позволяет создавать и изменять модели WebCAD программно — декларативными операциями в формате JSON. Им пользуются ИИ-агенты (например, Claude Code) и скрипты: можно построить деталь из терминала, пока приложение открыто в браузере, или вообще без браузера.

## Возможности {#features}

- Операции: переменные, эскизы из фигур (прямоугольники, окружности, линии, дуги, пазы, многоугольники, точки), выдавливание, вращение, скругления, фаски, оболочки, отверстия (в том числе [стандартные ISO](hole#standard) с резьбой), массивы (в том числе [по кривой](curve-pattern)), зеркало, [рёбра жёсткости](rib), [операции с гранями](move-face), булевы операции, плоскости, соединители, сечение и любые другие фичи с «сырыми» параметрами.
- [Сборки](assembly): создать вкладку сборки, вставить детали и подсборки (в том числе [гибкие](assembly-subassemblies#flexible)), расставить и зафиксировать экземпляры, сопрячь их (грани и рёбра находятся теми же запросами), объединить в группы, добавить связи сопряжений, сделать [разнесённые виды](assembly-exploded) (сдвиги и повороты экземпляров по шагам). Один вызов может построить детали и сразу собрать из них сборку.
- [Анимация сопряжения](assembly-motion#animate) как запрос: где по кадрам движения сопряжения стоят движущиеся экземпляры (положение и габариты) — например, чтобы проверить, не задевают ли детали друг друга. Документ при этом не меняется.
- [Производная геометрия](derived): подключить детали и эскизы другой Part Studio документа или [версии](derived#versions) (этого или другого документа) и строить по ним (эскиз с проекцией Use, выдавливание областей подключённого эскиза).
- [Конфигурации](configurations): задать таблицу вариантов (параметры фич, размеры эскизов, отключение фич, переменные; входы-списки, флажки и переменные), выбрать вариант и дать экземпляру сборки свой вариант.
- [Чертежи](drawings): лист с основной надписью (своей или по ГОСТ), [стандартные виды](drawings#views) детали или сборки в подходящем масштабе, проекционные виды, [разрезы и выносные элементы](drawings#section), размеры по вершинам и окружностям модели (они следуют за моделью), выноски отверстий, примечания, [спецификация с номерами позиций](drawings#bom); [экспорт](drawings#export) листа в PDF, SVG и DXF — и в браузере, и без него.
- [Версии и ветви](versions): сохранить версию, создать [ветвь](versions#branches) из версии, перейти в другое рабочее пространство, влить ветвь в текущее. Без браузера версии хранятся в [файле проекта](versions#file).
- Запросы граней, рёбер и деталей по геометрии («верхняя плоская грань», «рёбра, параллельные Z»).
- Отчёт о модели: фичи и их ошибки, переменные, детали с габаритами, объёмом и площадью; для сборки — её экземпляры (положение и габариты) и выполнено ли каждое сопряжение.
- Скриншоты графической области (в том числе разнесённого вида сборки) и экспорт (STL, STEP — сборка с деревом изделия, файл проекта, чертёж в PDF / SVG / DXF).
- Все операции одного вызова применяются **одним шагом отмены** — их можно отменить `Ctrl+Z` в приложении. Исключение — операции версий: версия, ветвь и слияние выполняются сразу, по порядку, как в панели «Версии».

## Как запустить {#usage}

В папке проекта WebCAD:

```bash
npm run agent -- status                 # открытые вкладки WebCAD
npm run agent -- create "Пластина"      # новый документ во вкладке
npm run agent -- run '[{"op":"sketch","shapes":[{"type":"rect","center":true,"w":40,"h":30}]},{"op":"extrude","depth":10}]'
npm run agent -- shot plate.png iso     # снимок графической области
npm run agent -- build ops.json --out model.webcad.json --stl model.stl   # без браузера
npm run agent -- run '[{"op":"drawing","of":"Part Studio 1"}]'           # чертёж со стандартными видами
npm run agent -- export pdf plate.pdf   # чертёж в PDF
```

На открытой странице те же методы доступны в консоли как `window.webcad`.

## Для разработчиков {#reference}

Полный справочник операций, запросов и формата отчёта — файл `docs/agent-api.md` в репозитории WebCAD. Он рассчитан на разработчиков и агентов и поэтому в эту справку не входит.

> **Примечание.** Пока открыт диалог фичи или эскиз, изменения через Agent API отклоняются — завершите или отмените правку.
