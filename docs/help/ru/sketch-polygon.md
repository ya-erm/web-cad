# Многоугольник

Рисует правильный многоугольник со вспомогательной окружностью. Как в Onshape, инструментов два — они отличаются тем, какой размер задаёт окружность:

| Инструмент | Окружность | Её диаметр — это размер |
|---|---|---|
| **Многоугольник по вписанной окружности** | Касается сторон (вписана в многоугольник) | «Под ключ» — между противоположными сторонами |
| **Многоугольник по описанной окружности** | Проходит через вершины (описана вокруг многоугольника) | «По углам» — между противоположными вершинами |

Если важен размер под гаечный ключ (гайка, шестигранник), берите **по вписанной окружности**; если важен размер по углам — **по описанной**.

**Панель эскиза:** **Многоугольник по вписанной окружности**, **Многоугольник по описанной окружности**

## Порядок действий {#steps}

1. Выберите инструмент многоугольника.
2. Щёлкните центр.
3. Щёлкните вторую точку — она задаёт размер и поворот:
   - **по вписанной окружности** — это середина стороны;
   - **по описанной окружности** — это вершина.
4. Задайте [число сторон](#sides) и щёлкните ещё раз (или нажмите `Enter`).
5. При желании сразу введите диаметр вспомогательной окружности в появившемся поле [быстрого размера](sketch#quick-dimensions) и нажмите `Enter`.

`Esc` отменяет многоугольник на любом шаге.

## Число сторон {#sides}

Рядом с курсором показывается подсказка **Стороны: 6**. Число сторон — от 3 до 50:

- **Курсором.** После второго щелчка отводите курсор от центра — сторон становится больше, ведите к центру — меньше.
- **С клавиатуры.** Наберите число цифрами (например, `8`), `Backspace` стирает цифру. Набирать можно и до второго щелчка.

Выбранное число запоминается для следующего многоугольника.

## Что создаётся {#result}

- Равные стороны (ограничения равенства), соединённые в вершинах.
- Вспомогательная окружность: по описанной — через все вершины; по вписанной — касается всех сторон (ограничения касания). Её [диаметр](sketch-dimensions) задаёт размер многоугольника.
- У многоугольника по вписанной окружности с чётным числом сторон — ещё вспомогательный радиус от центра к середине первой стороны, перпендикулярный ей: без него равные стороны вокруг окружности могли бы «перекоситься» в ромб.
- Центр, поставленный на точку или в начало координат, привязывается к ней.

> **Ограничение.** Число сторон у готового многоугольника не меняется (как и в Onshape): удалите его и нарисуйте заново.
