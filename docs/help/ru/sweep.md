# Сдвиг по траектории

Протягивает профиль (область эскиза или плоскую грань) вдоль траектории — цепочки кривых эскиза или рёбер. Так делают трубы, поручни, пружины по траектории и т. п.

**Панель инструментов:** **Сдвиг по траектории**

## Порядок действий {#steps}

1. Нарисуйте траекторию в одном эскизе, а профиль — в другом, на плоскости, пересекающей начало траектории (обычно перпендикулярной ей).
2. Нажмите **Сдвиг по траектории**.
3. В поле **Грани и области эскиза** выберите профиль.
4. Щёлкните поле **Траектория** и выберите кривые эскиза или рёбра. Они должны образовывать одну связную цепочку.
5. Нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Новая** / **Добавить** / **Вычесть** / **Пересечь** | Тип операции. |
| **Грани и области эскиза** | Профили. Внутренние контуры профиля (отверстия) сохраняются — получается труба. |
| **Траектория** | Кривые эскизов, рёбра деталей или [спираль](helix#spring), соединённые концами. |
| **Сохранять ориентацию профиля** | Профиль ведётся по траектории с минимальным закручиванием. Без флажка ориентация профиля следует изгибам траектории (трёхгранник Френе). Если результат выглядит перекрученным, попробуйте переключить флажок. |
| **Объединить со всеми** / **Область объединения** | С какими деталями выполнять операцию (кроме **Новая**). |

Сообщение «Рёбра траектории должны быть соединены» означает, что выбранные кривые не образуют непрерывную цепочку.

## Поверхность {#surface}

Переключатель **Твёрдое тело / Поверхность** вверху диалога. В режиме **Поверхность** протягиваются **Кривые эскиза и рёбра** — незамкнутые или замкнутые; кривые, соединённые концами, идут одной цепочкой. Получается [поверхность](offset-surface#surfaces) «Surface N» без толщины: замкнутая кривая даёт трубку без торцов, а не сплошное тело. **Сохранять ориентацию профиля** действует так же, как для тела; булевы операции к поверхности не применяются.

Пример: окружность радиусом 5 мм на плоскости **Top**, протянутая по вертикальному отрезку длиной 15 мм, даёт боковую поверхность цилиндра площадью 2π·5·15 ≈ 471,2 мм² — без дна и крышки.
