# Горячие клавиши

Сочетания привязаны к физическим клавишам, поэтому работают и в русской раскладке. На macOS вместо `Ctrl` можно нажимать `Cmd`. Пока курсор находится в текстовом поле, клавиши-сокращения не действуют.

## Общие {#general}

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` | Отменить |
| `Ctrl+Y`, `Ctrl+Shift+Z` | Повторить |
| `F1` | Справка по текущему инструменту или диалогу |
| `Esc` | Закрыть диалог фичи без сохранения / снять выбор |
| `Enter` | Принять диалог фичи |
| `Shift+Enter` | Принять диалог и сразу начать такую же фичу |
| `Space` | Снять выбор |
| `Del`, `Backspace` | Удалить фичи, выбранные в списке фич |

## Фичи Part Studio {#features}

| Клавиши | Действие |
|---|---|
| `Shift+S` | [Эскиз](sketch) |
| `Shift+E` | [Выдавливание](extrude) |
| `Shift+W` | [Вращение](revolve) |
| `Shift+F` | [Скругление](fillet) |

Остальные фичи запускаются кнопками панели инструментов или через поле **Поиск инструментов**.

## Вид {#view}

| Клавиши | Действие |
|---|---|
| `F` | Показать всё |
| `N` | Вид по нормали |
| `Shift+1` … `Shift+6` | Виды Front, Back, Left, Right, Top, Bottom |
| `Shift+7` | Изометрия |
| `←` `→` `↑` `↓` | Повернуть вид на 15° |
| `Shift` + стрелка | Повернуть вид на 90° |
| `Shift+Z` / `Z` | Приблизить / отдалить |
| `P` | Показать или скрыть плоскости |
| `Shift+H` | Показать или скрыть эскизы |

## Эскиз: инструменты {#sketch-tools}

| Клавиши | Инструмент |
|---|---|
| `L` | [Линия](sketch-line) |
| `G` | [Прямоугольник по углам](sketch-rectangle) |
| `R` | [Прямоугольник от центра](sketch-rectangle) |
| `C` | [Окружность по центру](sketch-circle) |
| `A` | [Дуга по 3 точкам](sketch-arc) |
| `Shift+A` | [Касательная дуга](sketch-arc#tangent) |
| `Shift+S` | [Точка](sketch-point) |
| `Shift+F` | [Скругление в эскизе](sketch-fillet) |
| `M` | [Обрезка](sketch-trim) |
| `O` | [Смещение](sketch-offset) |
| `U` | [Проецирование (Use)](sketch-use) |
| `D` | [Размер](sketch-dimensions) |
| `Q` | [Вспомогательная геометрия](sketch#construction) |
| `Shift+C` | Показать или скрыть ограничения |
| `Esc` | Прервать действие инструмента → снять выбор → вернуться к выбору |
| `Enter` | Завершить действие инструмента, иначе — завершить эскиз |
| `Del`, `Backspace` | Удалить выбранное |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить в эскизе |

## Эскиз: ограничения {#constraints}

Сначала выберите элементы, затем нажмите клавишу. Подробнее — [Ограничения](sketch-constraints).

| Клавиши | Ограничение |
|---|---|
| `I` | Совпадение |
| `Shift+O` | Концентричность |
| `B` | Параллельность |
| `T` | Касание |
| `H` | Горизонтальность |
| `V` | Вертикальность |
| `Shift+L` | Перпендикулярность |
| `E` | Равенство |
| `Shift+M` | Середина |
| `Shift+Q` | Симметрия |
| `Shift+J` | Фиксация |

## Чертёж {#drawing}

| Клавиши | Действие |
|---|---|
| `D` | Размер |
| `F` | Показать весь лист |
| `Esc` | Инструмент выбора, снять выбор |
| `Del`, `Backspace` | Удалить выбранный вид, размер или примечание |

## Сборка {#assembly}

| Клавиши | Действие |
|---|---|
| `I` | [Вставить](assembly#create) детали из Part Studio |
| `J` | Новое [сопряжение](assembly-mates#mates) |
| `Del` | Удалить выбранные экземпляры |

## Справка {#help}

| Клавиши | Действие |
|---|---|
| `/` | Перейти в поле поиска |
| `Esc` | Очистить поиск |
| `Enter` в поле поиска | Открыть первый результат |
