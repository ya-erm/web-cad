# Лофт

Строит тело, плавно переходящее через несколько профилей, расположенных на разных плоскостях. Первым и последним «профилем» может быть точка — тогда тело сходится в вершину.

**Панель инструментов:** **Лофт**

## Порядок действий {#steps}

1. Нарисуйте профили в эскизах на разных плоскостях (например, на плоскостях, созданных фичей [Плоскость](plane) со смещением).
2. Нажмите **Лофт**.
3. В поле **Профили** выберите профили **по порядку** — от первого к последнему. Первым или последним можно выбрать точку эскиза или вершину.
4. При необходимости включите **Линейчатый**, нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Новая** / **Добавить** / **Вычесть** / **Пересечь** | Тип операции. |
| **Профили** | Области эскизов, плоские грани, точки эскизов или вершины. Нужно не меньше двух элементов. |
| **Линейчатый** | Соседние профили соединяются прямыми (линейчатыми) поверхностями вместо гладкого перехода. |
| **Объединить со всеми** / **Область объединения** | С какими деталями выполнять операцию (кроме **Новая**). |

> **Ограничение.** У каждого профиля используется только внешний контур; направляющие кривые и сопоставление вершин профилей пока не поддерживаются.
