# Спираль

Строит винтовую линию (спираль) вокруг оси.

**Панель инструментов:** **Спираль**

## Порядок действий {#steps}

1. Нажмите **Спираль**.
2. В поле **Ось** выберите цилиндрическую грань, круговое ребро, линию эскиза или прямое ребро.
3. Задайте **Радиус**, **Шаг** и **Витков**; при необходимости включите **Левая**.
4. Нажмите ✓ (`Enter`).

## Параметры {#options}

| Поле | Описание |
|---|---|
| **Ось** | Ось спирали. Если выбрана цилиндрическая грань или круговое ребро, спираль ложится на их радиус, и поле **Радиус** не используется. |
| **Радиус** | Радиус спирали (по умолчанию 10 мм) — для оси-линии. |
| **Шаг** | Расстояние между витками вдоль оси (по умолчанию 5 мм). |
| **Витков** | Число витков (может быть дробным; по умолчанию 5). Высота спирали = шаг × число витков. |
| **Левая** | Левая навивка вместо правой. |

Спираль строится вдоль оси от её начальной точки (для кругового ребра — от его центра) и показывается в графической области как кривая; её можно скрыть значком глаза в списке фич.

## Пружина: сдвиг по спирали {#spring}

Спираль выбирается щелчком в графической области, как кривая эскиза, — например, в поле **Траектория** [сдвига](sweep):

1. Постройте спираль.
2. Нарисуйте профиль (например, окружность) в эскизе на плоскости, проходящей через начало спирали поперёк её хода. Для спирали вокруг оси Z начало лежит на плоскости **Front**.
3. Нажмите **Сдвиг по траектории**, выберите профиль, затем щёлкните поле **Траектория** и щёлкните саму спираль — в поле появится её имя.
4. Нажмите ✓.

Наведённая или выбранная спираль подсвечивается; правый щелчок по ней открывает меню с пунктом **Редактировать**.
