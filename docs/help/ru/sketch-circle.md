# Окружность

| Инструмент | Клавиша | Как задаётся |
|---|---|---|
| **Окружность по центру** | `C` | Центр и точка на окружности. |
| **Окружность по 3 точкам** | — | Три точки на окружности. |

## Порядок действий {#steps}

**Окружность по центру:**

1. Нажмите **Окружность по центру** (`C`).
2. Щёлкните центр.
3. Щёлкните точку на окружности (или наберите диаметр в поле [быстрого размера](sketch#quick-dimensions) и нажмите `Enter`).

**Окружность по 3 точкам:**

1. Нажмите **Окружность по 3 точкам**.
2. Щёлкните три точки, через которые должна пройти окружность.

## Особенности {#details}

- Центр, поставленный на точку эскиза, совпадает с ней; поставленный в начало координат — фиксируется в нём.
- Если точка на окружности (или любая из трёх точек) поставлена на существующую точку, эта точка оказывается на окружности (ограничение совпадения точки с кривой).
- После построения предлагается поле **диаметра**.
- Окружность, взятую за край, можно перетащить, чтобы изменить радиус; за центр — чтобы переместить.
