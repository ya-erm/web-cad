# Дуга

| Инструмент | Клавиша | Как задаётся |
|---|---|---|
| **Дуга по 3 точкам** | `A` | Начало, конец и точка на дуге. |
| **Касательная дуга** | `Shift+A` | Продолжает линию или дугу по касательной. |
| **Дуга по центру** | — | Центр, начало и конец. |

## Дуга по 3 точкам {#three-point}

1. Нажмите **Дуга по 3 точкам** (`A`).
2. Щёлкните начальную точку, затем конечную.
3. Щёлкните третью точку — через неё пройдёт дуга (она определяет радиус и сторону выпуклости).

Начало и конец, поставленные на существующие точки, получают ограничения совпадения.

## Касательная дуга {#tangent}

1. Нажмите **Касательная дуга** (`Shift+A`).
2. Щёлкните конечную точку существующей линии или дуги — дуга начнётся из неё по касательной.
3. Щёлкните конечную точку дуги.

Дуга получает ограничения совпадения с начальной точкой и касания с исходной кривой. Если щёлкнуть не в конец линии или дуги, появится сообщение «Начните касательную дугу с конца линии или дуги».

## Дуга по центру {#center}

1. Нажмите **Дуга по центру**.
2. Щёлкните центр, затем начальную точку (она задаёт радиус).
3. Щёлкните, где дуга должна закончиться: важен только угол, радиус остаётся прежним.

Дуга строится против часовой стрелки от начальной точки к конечной.

## Особенности {#details}

- После построения дуги по 3 точкам или по центру предлагается поле [быстрого размера](sketch#quick-dimensions) для **радиуса**.
- Радиус дуги можно задать [размером](sketch-dimensions) (`R`), две дуги — уравнять [равенством](sketch-constraints).
