# Перпендикулярность

Делает линии перпендикулярными.

**Панель эскиза:** **Перпендикулярность** · **Клавиша:** `Shift+L`

```figure
image: ../images/constraint-perpendicular.svg
alt: Угол между линиями становится прямым
caption: Схема: 1 — до ограничения, 2 — после. Точное положение элементов зависит от остальных ограничений эскиза.
width: 600
```

## Что выбрать {#select}

Две или больше линий: каждая становится перпендикулярной первой выбранной. Если линий меньше двух — «Выберите две линии».

## Как работает {#how}

- Обе линии поворачиваются, каждая на часть угла, пока между ними не станет 90°.
- Сохраняется «сторона» поворота: линия, отклонённая против часовой стрелки, станет перпендикулярной в ту же сторону, а не перевернётся.
- Линии не обязаны пересекаться: перпендикулярны их направления.

## Применение {#uses}

- Прямые углы в произвольно повёрнутых контурах.
- Вместе с [горизонтальностью](constraint-horizontal) первой линии — вертикальность второй, без отдельного ограничения.

## Удаление {#delete}

Щёлкните значок ⊥ и нажмите `Del`.
