# Паз

Рисует прямой паз: две полуокружности, соединённые касательными отрезками.

**Панель эскиза:** **Паз**

```figure
image: ../images/sketch-slot-steps.svg
alt: Центры торцевых дуг и радиус паза
caption: 1 и 2 — центры полуокружностей; 3 задаёт радиус. Полная ширина паза равна двум радиусам.
width: 600
```

## Порядок действий {#steps}

1. Нажмите **Паз**.
2. Щёлкните центр первой полуокружности.
3. Щёлкните центр второй полуокружности.
4. Щёлкните, чтобы задать ширину паза (расстояние от оси до курсора — радиус).
5. При желании наберите радиус в поле [быстрого размера](sketch#quick-dimensions) и нажмите `Enter`.

## Что создаётся {#result}

- Две дуги одинакового радиуса (ограничение равенства) и два отрезка, касательные к ним.
- Вспомогательная ось между центрами дуг. Её длину и положение задают [размерами](sketch-dimensions).
- Центры, поставленные на существующие точки, получают ограничения совпадения.
