# План развития WebCAD

Цель — приблизить WebCAD к Onshape по функциям и качеству, оставаясь офлайн-приложением без регистрации.
Порядок разделов — порядок приоритета. Отмечайте сделанное `[x]` и дописывайте новое по мере работы.
Каждая новая функция сопровождается тестами, проверкой в браузере и страницами справки на всех языках
(`docs/help/`), а где уместно — операциями API агента (`docs/agent-api.md`).

## Режим работы: постоянный цикл (/loop)

Работа идёт непрерывно в цикле `/loop`, план не «закрывается» — когда пункты кончаются, добавляются новые.
Каждая итерация:

1. **Выбрать задачу**: сначала свежие просьбы пользователя и ошибки, затем следующий невыполненный пункт
   этого плана, затем — то, что сильнее всего отличает WebCAD от Onshape (сверяться со справкой Onshape
   https://cad.onshape.com/help/ и, при необходимости, с вкладкой Onshape — ничего там не меняя).
2. **Сделать**: реализовать функцию или исправить ошибку, покрыть тестами.
3. **Проверить качество**: `npx tsc -p tsconfig.app.json --noEmit`, `npm test`, проверка в браузере
   (не трогая документы пользователя без нужды), `npm run build`.
4. **Записать**: отметить пункт `[x]`, дописать найденные по ходу ошибки и пробелы как новые пункты,
   обновить справку (`docs/help/`) и, если нужно, API агента.
5. **Отчитаться** кратко по-русски: что сделано и что дальше — и запланировать следующую итерацию.

Помимо новых функций, в каждой итерации по возможности: исправлять найденные ошибки, улучшать качество
(поведение, отображение, удобство, скорость), приводить интерфейс и терминологию ближе к Onshape.

- [x] Сопряжения через mate connector: жёсткое, поворотное, ползун, цилиндрическое, плоское, шаровое — явные соединители деталей и неявные на гранях / рёбрах / вершинах, разворот оси, поворот на 90°, живое превью, список «Сопряжения» (редактирование, подавление, удаление), пересчёт при изменениях; клавиша `J`

- [x] Триада: ввод расстояния / угла щелчком по стрелке или дуге (с единицами и выражениями), перенос на соединитель экземпляра `Alt`+щелчком с выравниванием по его осям, возврат `Alt`+щелчком по центру
- [x] Решатель сопряжений: замкнутые контуры (Левенберг–Марквардт по всем свободным экземплярам после обхода от фиксированных; четырёхзвенник), смещение вдоль Z, ограничения хода (сдвиг / поворот) в диалоге сопряжения
- [x] Сопряжения «Параллельное» и «Штифт в пазу» (Onshape Parallel / Pin slot); группы (Group): кнопка на панели, список, «Запомнить текущее положение», подавление, разгруппировка; ввод положения участника ведёт за собой свободную группу
- [x] Связи сопряжений (Gear, Rack and pinion, Screw) с непрерывным отсчётом угла: диалог, список, ведущий экземпляр при перетаскивании и вводе (остальные подстраиваются вокруг него); решатель переведён на демпфирование Левенберга
