# WebCAD

Браузерная офлайн CAD-система по образцу Onshape (Vite + React + TypeScript, ядро OpenCascade через replicad в Web Worker). Описание возможностей — README.md.

## Проверки

- `npx tsc -p tsconfig.app.json --noEmit` — типы приложения (`tsconfig.node.json` — для vite.config.ts)
- `npm test` — vitest (в т.ч. реальное ядро OpenCascade в Node)
- `npm run build` — сборка PWA в `dist/`
- dev-сервер `npm run dev` (http://localhost:5173) запускается без HMR: после правок перезагрузите страницу

## Версия

Версия приложения — semver в `package.json` (показывается в нижней строке как `v0.25.0`, дата и хеш коммита — в подсказке). Перед коммитом повышайте её: коммит с новыми функциями (инструменты, фичи, режимы) — `npm version minor --no-git-tag-version`; коммит с исправлениями и мелкими улучшениями удобства (область кнопки, подсказка, кнопка-сокращение вроде «Скрыть все») — `npm version patch --no-git-tag-version`; мажорную — только по решению пользователя. 0.14.0 — первый коммит с semver: начальный коммит и 12 следующих с функциями. Теги git не ставьте без просьбы.

## План работ

Приоритеты развития — в `docs/roadmap.md`: берите следующий невыполненный пункт сверху, отмечайте сделанное `[x]` и дописывайте новые пункты по просьбам пользователя.

## Временные файлы

Черновые файлы (превью, скриншоты, скрипты операций, сравнения значков) кладите в `temp/` внутри проекта, а не в `/tmp`: папка в `.gitignore`, её не собирает Vite и не проверяют тесты.

## Документация для пользователей

Справка в стиле Onshape лежит в `docs/help/<lang>/<page>.md` (сейчас `ru` и `en`, оглавление — `docs/help/toc.json`) и открывается в приложении (`#/help/<lang>/<page>`). Добавляя или меняя функциональность, обновляйте соответствующие страницы на всех языках (или добавляйте новые и вносите их в `toc.json`); описывайте только то, что реально работает.

## Модели по просьбе пользователя: Agent API

Чтобы создать или изменить 3D-модель, используйте Agent API — справочник в `docs/agent-api.md`:

- приложение открыто в браузере (dev-сервер запущен) → `npm run agent -- status`, затем `create` / `open`,
  `run <ops>` и `shot <png>` для проверки результата глазами;
- без браузера → `npm run agent -- build ops.json --out model.webcad.json --stl model.stl`.

Если подключено несколько вкладок WebCAD, выберите нужную через `--tab <id>`; если неясно, в какой
вкладке или документе работать, спросите пользователя. Не удаляйте и не перезаписывайте документы
пользователя без его просьбы: правки делаются операциями `run` (один шаг отмены).
